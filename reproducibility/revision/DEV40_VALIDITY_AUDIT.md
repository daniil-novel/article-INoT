# DEV40 development-task validity audit

Scope: IDs assigned for the development generation pass (the 32 IDs below). I compared the model-facing `prompt` and `context` fields in `data/bigcodebench-split/prepared.jsonl` (the context includes the supplied imports/constants/function stub) with the original `test` field in `data/bigcodebench-v0.1.4.jsonl`. This is a cursory contract audit, not a proof that an implementation is correct. “Reviewed” is the concrete evidence seen; “uncertain” records what the supplied prompt/tests do not establish.

- **1029 — Reviewed:** `test_dataframe_*` checks shape, column names, and alphabet membership while seeding NumPy; **uncertain:** no test checks the generated values against a specified seed or rejects negative dimensions, so reproducibility and edge-case behavior are outside the contract exercised.
- **894 — Reviewed:** `prompt` says integers are generated “between 1 and 100,” while `test_case_1/3/4/5` hard-code exact means/stds; **finding:** the inclusive-versus-exclusive endpoint convention is not explicit, and exact floating-point fixtures are implementation/RNG-version sensitive. **Uncertain:** the tests and supplied context do not establish whether 100 must be reachable.
- **858 — Reviewed:** `prompt` promises an optional seed for consistent randomness; `test_randomness_without_seed` requires two calls to differ; **uncertain:** that assertion is probabilistic, and the supplied contract does not say whether seeding may alter the module-global `random` generator.
- **678 — Reviewed:** prompt requires alphabetical JSON processing and moving files to `processed`, but `test_basic_operation`, `test_single_file`, and `test_non_json_files` only assert row counts; **finding:** ordering, source-column values, and file movement are untested. **Uncertain:** the phrase “path may not exist initially” does not make clear whether the source path or only `processed` should be created.
- **451 — Reviewed:** `test_case_1` computes a separate PCA only to assert `sum(explained_variance_ratio_) <= 1`; `test_case_6` checks seeded repeatability; **uncertain:** no assertion ties the returned transformed data to the documented input-generation/PCA semantics, so a shape-correct unrelated array could pass.
- **734 — Reviewed:** prompt invokes NLTK downloads and tests hard-code POS-tag dictionaries (`test_case_1`–`5`); `test_case_4` even says “might be tagged ... UH”; **finding:** outcomes depend on installed NLTK tagger/model version and the tests acknowledge an alternative while still requiring one exact dictionary.
- **374 — Reviewed:** only `test_case_1` calls `task_func`; `test_case_2` and `test_case_3` inspect newly loaded workbooks without invoking it; **finding:** most-sheet/no-quote behavior is not actually tested, and the required “all double quotes” transformation is only partially exercised.
- **855 — Reviewed:** tests assert only total count, key-count upper bounds, and membership in `VALID_CHARACTERS`; **uncertain:** the prompt leaves random state and behavior for zero/negative sizes unspecified, and the suite cannot detect many incorrect distributions.
- **573 — Reviewed:** `test_statistics_values` calls `np.random.seed(42)` but the supplied test imports only `unittest` and `matplotlib.pyplot`; **finding:** the test has an undeclared `np` dependency (unless an external harness injects it), while `test_negative_length` imposes a `ValueError` not stated in the prompt.
- **964 — Reviewed:** prompt says every converted file becomes a CSV with one `Text` column, but `test_case_1`–`4` only check output existence/count; **finding:** the central output-content contract is untested, including whether CSV/XLSX inputs are reduced to `Text`.
- **303 — Reviewed:** prompt documents a phase “between 0 and 1,” while every test asserts only `-1 <= result <= 1`; **finding:** the test admits negative outputs and does not validate the lunar-phase calculation or the 7-year reference rule.
- **533 — Reviewed:** prompt explicitly requires different invocations to differ because of a random salt, and `test_different_salts_different_hashes` uses `assertNotEqual`; **uncertain:** this is probabilistic and the suite does not verify salt use, custom-alphabet encoding, or encoded-value validity beyond type checks.
- **155 — Reviewed:** prompt fixes `COLUMN_NAMES` to eight names; all tests pass 8-column arrays and assert shape/averages/plot line; **uncertain:** behavior for non-2D input or a column count other than eight is unspecified and untested.
- **681 — Reviewed:** `test_case_1`–`5` call the function and verify removal of the key from the returned frame and rewritten JSON; **uncertain:** there is no test for an empty list, malformed JSON, or a key absent from some records, despite “each object” in the prompt.
- **1110 — Reviewed:** prompt says “dictionary of words as keys and letters as values” and asks for letters in the words; `test_case_1`–`5` build expected counts from concatenated dictionary keys, matching the canonical solution; **finding:** no contradiction is established. **Uncertain:** the value field is semantically redundant, and no test clarifies whether values should ever affect counting.
- **421 — Reviewed:** tests patch `requests.post` with local mocks in `test_upload_success` and `test_urls`; `test_invalid_url` is unpatched and only expects a broad `Exception`; **finding:** validity is tied to an implementation-specific mock and one path may perform real network/URL handling; request payload, metadata, and one-second delay are not checked.
- **839 — Reviewed:** `test_case_1` asserts an exact 10-row CSV fixture for `seed=12`; other tests check ranges and row counts; **uncertain:** exact output depends on Python `random` behavior and list ordering, while the prompt’s example has malformed `countries['Albania'...` syntax.
- **745 — Reviewed:** prompt requires returning “the full path of the script,” while tests/comments call the result a base name and assert `subprocess.call(script_name, shell=True)`; **finding:** return/path semantics are contradictory, and `test_random_script_selection` can fail by chance after ten draws.
- **107 — Reviewed:** prompt requires a KMeans scatter plot and named labels; tests check only one collection, exceptions, and labels; **uncertain:** no test verifies date ordinal conversion, cluster assignments, or use of `random_state`, so the substantive computation is weakly constrained.
- **356 — Reviewed:** prompt specifies a 2D phase array and errors for non-arrays/mismatched lengths; `test_empty_arrays` expects `Z.size == 0` while the prompt gives no empty-input rule; **uncertain:** empty-input behavior is an extra unstated contract, and the test checks only `Z[0]` for the nonempty calculation.
- **615 — Reviewed:** prompt specifies only columns and random goals/penalties; tests parse an exact string format `"(N goals, $N)"`, assume five fixed teams and penalty cost 1000, and require negatives to be treated as absolute values; **finding:** several required values/format rules are undisclosed in the prompt and are inferred from tests/canonical code.
- **640 — Reviewed:** prompt requires two visualizations, but all tests (`test_dataframe_*`) inspect only the returned frame’s shape/index/range/type; **finding:** line plot, heatmap, titles, and figures are completely untested; random output is intentionally unconstrained.
- **814 — Reviewed:** prompt says to write matching paths to a configuration file and return its path; tests instead expect files moved and an integer count (`test_valid_files_moved`, `test_target_directory_creation`); **finding:** direct output/side-effect contradiction between instruction and test.
- **757 — Reviewed:** model-facing text contains the damaged phrase “words separated by. `""`,” while every test uses `.` (`test_case_1`–`5`); **finding:** the formatting is corrupted, but the period immediately before the damaged quotation marks and the tests make `.` the likely delimiter. **Uncertain:** the prompt rendering does not state that delimiter cleanly.
- **464 — Reviewed:** tests cover datetime, Decimal, null, lists, and unsupported objects; `test_simple_object_serialization` requires exact default JSON spacing; **uncertain:** prompt leaves Decimal representation and key-order/format guarantees implicit, while exact-string checking makes formatting part of the hidden contract.
- **892 — Reviewed:** prompt says “a specific pattern” but never names it; tests imply `}` and require ten random choices (`test_case_1`–`5`), with only broad count ranges except zero-pattern cases; **finding:** the pattern and sampling policy are undisclosed and random, so many incompatible implementations pass.
- **468 — Reviewed:** prompt requires numeric conversion, plotting, and cube roots; `test_case_3` expects string numerics converted to floats, while `test_case_4` expects a generic `Exception` for nonnumeric strings; **uncertain:** exception type/message and plot details are not specified, and the broad exception assertion masks contract differences.
- **549 — Reviewed:** tests decode the Base64 CSV and compare frames; **uncertain:** empty-frame behavior, CSV dialect, index handling, and type preservation are not stated beyond round-trip fixtures; no direct assertion checks that the returned string is valid Base64 except through decode.
- **529 — Reviewed:** seeded tests check plot existence/labels and one exact distribution (`test_case_7`); **uncertain:** prompt does not define invalid/zero/negative roll inputs or whether all possible sums must appear as bars, leaving edge behavior and visualization completeness unresolved.
- **1022 — Reviewed:** prompt/test both filter relative to “current date,” but `setUp` calls `datetime.now()` repeatedly and tests use today-relative fixtures; **finding:** results are wall-clock dependent and can race across midnight; no timezone policy is specified. `test_empty_file` also relies on pandas’ `EmptyDataError` behavior.
- **173 — Reviewed:** tests assert only country index order and GDP range; prompt permits simulated random values but gives no seed; **uncertain:** duplicate countries, non-string values, and ordering for unusual dictionaries are unspecified, and reproducibility is not tested.
- **544 — Reviewed:** prompt says convert a hex string to a binary32 float and compress it; `test_boundary_hex_value` passes `FFFFFFFF` and expects `bytes`, while the canonical code packs `int(hex_string, 16)` as `!f`; **finding:** the contract is ambiguous between interpreting the hex as a numeric integer and reinterpreting it as binary32 bits. **Uncertain:** `0xFFFFFFFF` is numerically within the float32 range, but its exact `struct.pack` behavior and intended representation are not clarified by the prompt/tests.

No model answers or held-out confirmatory tasks were inspected, and no task was removed from the assigned set.

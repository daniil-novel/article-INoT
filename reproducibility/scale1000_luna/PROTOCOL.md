## Statistical decision rules

For each task and arm, average the three binary outcomes. This estimates
per-generation test success, not pass@3 or best-of-three selection. The task
is the paired inference unit; do not use 3000 repeats or 15000 candidates as
independent sample size. A primary contrast requires all three outcomes in
both arms. Report exclusions, observed and all-assignment extreme bounds.

The primary family contains SR-SN, MR-MN, MN-SN and MR-SR. For each, test the
two-sided zero mean task-level difference with a paired t-test on the task
means (large-sample approximation), then apply Holm across exactly these
four primary p-values, familywise alpha .05. This explicitly replaces the
single-repeat McNemar rule for this new repeated dataset; the historical
McNemar analyses remain unchanged. Resample whole tasks, retaining all repeat
outcomes together, for 10000-resample descriptive 95% bootstrap intervals
(analysis seed 20260909). Do not select the test from observed significance.
Discuss related tasks and provider drift as remaining dependence risks.

Interaction, direct-solver comparisons, old-200/new-800 subgroup estimates,
repeat variability and paired resources are descriptive. Report paired mean
token/valuation differences and ratios of means, with task-bootstrap intervals.
No equivalence, non-inferiority or joint monetary-superiority decision is made.
A power/precision sensitivity grid varies discordance, task-repeat correlation
and effect size before generation; it is an approximation, not a guarantee
that a two-percentage-point effect can be established.

tokens, USD 56.82 API-equivalent, or USD 67.88 without cache discounts for
15000 candidates. These are linear planning estimates from a different sample and model,
with substantial uncertainty and no guarantee that subscription quota suffices.
Five repeats would instead assign 25000 candidates, approximately USD 94.70
or USD 113.14 without cache discounts. Three repeats prioritize task breadth
within the previously discussed USD 300 resource envelope.

Use a USD 285 known API-equivalent submission guard, allowing already active
calls to terminate; this is a planning pause, not a cash billing cap. Preserve
unknown interrupted usage separately. Pricing is USD .20 input, .02 cached
input and 1.20 output per million; cached and reasoning tokens are subsets,
not added twice. No paid API calls, purchases or automatic quota-reset credit
redemptions are part of this protocol. Any reset requires explicit user consent.
The account-wide remaining quota is observed, not converted to a fictional
token allowance. Model assistant labor and evaluator compute are not included
in candidate valuation. Publish completed results only after all available
candidates have native reports; never represent this plan as executed data.

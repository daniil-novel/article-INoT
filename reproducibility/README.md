## Что использовано в статье

- `results/slide_e2e3_real/e3/runs.json` исследовательского репозитория:
  реальный OpenRouter-пилот E3 на HumanEval/0--HumanEval/4, Gemini 3.1 Pro

- `results/slide_e2e3_real/e2/**`: E2a--E2d на малой реальной выборке.
- `results/e6/**`: реальное сравнение Gemini 3.1 Pro Preview и Gemini 3.1

- `reproducibility/results/20260726_flash_lite/e3` в репозитории статьи:
  повтор E3 на HumanEval/0--HumanEval/19
  с Gemini 3.1 Flash-Lite и seed 42.
- `reproducibility/results/20260726_flash_lite/e4` в репозитории статьи:
  агрегированная диагностика согласия Flash-Lite PASS/REJECT с сохранённым
  исходом внешней проверки. Per-case решения и контрфактические исходы
  перезапуска не сохранены, поэтому это не проверка policy-эффекта H2.
- аналитическая экстраполяция стоимости инференса из реальных пар B2/B3
  публичного E3 на 10 000 задач с равным весом четырёх контекстных бакетов.

Файл `evidence_snapshot.json` генерируется из перечисленных JSON и хранит
сводные показатели, SHA-256 входных файлов, полные E2/E6-профили, парные
статистические сравнения, фактический диапазон proxy-компрессии и проверки
полноты бакетов. Восемь локализованных рисунков статьи в
`../figures/generated/` строятся тем же скриптом, без ручного переноса чисел.

## Канонический статус гипотез

- Ресурсный эффект H1 описательно наблюдается в фиксированных E3-выборках.
- Неухудшение качества на 2 п.п. не установлено.
- Policy-эффект H2 не оценён.
- H3 в прямом архитектурном пилоте не поддержана.
- Теоретический `tau_star` и порог маршрутизатора не идентифицированы.

## Исходные задачи

HumanEval загружается официальным загрузчиком исследовательского репозитория.
Для запусков с `n=20` берутся первые 20 задач в каноническом порядке:
`HumanEval/0`--`HumanEval/19`. Для каждой задачи общий контекст строится
детерминированно с seed 42 из промптов и эталонных решений других HumanEval-
задач; решение целевой задачи в контекст не включается. Контекст добавляется
целыми блоками, поэтому фактическая длина немного больше целевой.

Controlled-набор E6 содержит три циклически повторяемых семейства:
`reverse_words`, `count_peaks` и `normalize_path`. Он изолирует влияние длины
нерелевантного контекста, но слишком прост для сильных выводов о качестве:
в сохранённом E6 pass@1 равен 1.0 во всех бакетах.

Профиль `inot_flash_lite_real.yaml` фиксирует параметры повторного E3. Для
публичных E2/E3/E6 и нового E4 использован `config.yaml` исследовательского
commit выше. На дату
2026-07-26 применялись стандартные цены OpenRouter:

- [Gemini 3.1 Pro Preview](https://openrouter.ai/google/gemini-3.1-pro-preview/pricing):
  `$2.00` за 1 млн входных и `$12.00` за 1 млн выходных токенов;
- [Gemini 3.1 Flash-Lite](https://openrouter.ai/google/gemini-3.1-flash-lite/pricing):
  `$0.25` и `$1.50` соответственно.

Рубли вычисляются только как воспроизводимая локальная оценка по фиксированному
курсу 100 RUB/USD; научные выводы используют USD.

## Границы доказательности

- Значение `tau_star=256` из исходного агрегата исключено из канонических
  выводов. Пересечение не заключено внутри сетки 256--16 384 токена, а
  поведение ниже левого узла неизвестно; поэтому ни теоретический
  \(\tau^\star\), ни deployment-порог маршрутизатора не идентифицированы.
- Компрессор ограничивает сумму proxy-счётчиков выбранных блоков 4096
  токенами, но добавляет разделители после отбора. Поэтому сериализованное
  значение может быть немного выше: наблюдаемый максимум равен 4151 для
  Pro и 4170 для Flash-Lite. Это не жёсткий предел provider input tokens.
- Повтор E3 использует 20 разных задач и один seed, а модельный slug OpenRouter
  не является неизменяемым снимком весов; API-дрейф остаётся возможным.
- Встроенная SWE-bench Lite-проверка не запускает официальный контейнерный
  harness, поэтому её pass/fail нельзя трактовать как решение GitHub issue.
- Экстраполяция стоимости использует реальные E3-измерения API-инференса.
  Это не полный TCO, пока отдельно не измерены `C_hw`, `C_energy`, `C_storage`
  и `C_ops`.
- Сохранённые `runs.json` содержат идентификаторы задач, метрики и usage по
  ролям, но не полный текст сгенерированного решения. Это ограничивает
  постфактум-аудит отдельных ответов и отмечено в статье.
- Повтор E3 для seed 123 и отдельный E5 были запущены, но исключены: OpenRouter
  вернул `403` после достижения общего лимита ключа до сохранения полных
  результатов. Частичные значения в статье не используются.

# Проверка сходства исходных задач

Аудит всех 1 140 исходных задач и фиксированной выборки из 1 000 идентификаторов
выполнен без чтения ответов модели и их качества. Проверены исходный SHA-256,
хэши каждой выбранной строки, точное соответствие входам модели и разбиение
200/800. [Правила](PROTOCOL.md) записаны в `19d45ae` до расчёта этого аудита,
но после начала большой генерации и раскрытия прежних результатов mini.
Это дополнительная проверка, не первоначальная регистрация исследования.

| Разбиение выбранных задач | Групп | Максимальный размер |
|---|---:|---:|
| Сходство инструкций ≥0,50 | 996 | 3 |
| Сходство инструкций ≥0,70 | 999 | 2 |
| Сходство инструкций ≥0,90 | 1000 | 1 |
| Инструкции ≥0,70 + близкий код + точные совпадения | 992 | 3 |

В последнем разбиении семь групп включают 15 выбранных задач. Все остальные
задачи являются одиночными группами по данным правилам, что не доказывает
независимость их ошибок. Точного повтора нормализованной инструкции внутри
тысячи нет; у пары /130–/131 совпадает структура эталонной программы.

Между сериями найдены также совпадения: /1120 и /1121 из опыта на 80 задачах
имеют одинаковые инструкции и AST эталонов; /826 и задача разработки /814
имеют одинаковые AST. Все назначения сохраняются. Никакие задачи, ответы или
тесты не заменяются. Эта проверка не обнаруживает присутствие задач в обучении
закрытой модели и не объявляет близкие программы семантически тождественными.

Канонический результат: [source-audit-v2](source-audit-v2/summary.json).
В нём сохранены все 1 140 отпечатков, связи, разбиения и хэши источников.
Локальная предварительная версия v1 имела те же группы; v2 добавляет явную
категорию оставшихся резервных задач и проверку хэшей определений подвыборок.

Воспроизведение из корня репозитория, без модельных вызовов:

```text
python -m reproducibility.task_dependence.audit --output tmp/source-audit-replay
python -m reproducibility.evidence_manifest verify reproducibility/task_dependence/source-audit-v2
```

Четыре файла нового расчёта должны точно совпасть с соответствующими файлами
`source-audit-v2`. Существующая папка не перезаписывается.

После завершения обеих больших серий выполняются отдельные чувствительности:

```text
python -m reproducibility.task_dependence.sensitivity --study factorial --run-root reproducibility/runs/scale1000-luna-v1 --audit reproducibility/task_dependence/source-audit-v2 --output reproducibility/runs/scale1000-luna-v1/source-family-sensitivity
python -m reproducibility.task_dependence.sensitivity --study scc --run-root reproducibility/runs/scc1000-luna-v1 --audit reproducibility/task_dependence/source-audit-v2 --output reproducibility/runs/scc1000-luna-v1/source-family-sensitivity
```

Нужны зафиксированные зависимости публикации, включая NumPy. Анализ требует
завершённой генерации, основного анализа и полной матрицы назначений. Он
сначала усредняет три парных исхода внутри задачи, затем пересэмплирует
исходные группы. Основное среднее сохраняет одинаковый вес задач; среднее
с одинаковыми весами групп выводится отдельно. Сохраняются все 10 000 значений
каждого bootstrap-распределения, интервалы и диагностика числа/размера групп.
Семьи исходных тестов, правила пропусков и знаменатели не изменяются.

Оба публикационных сборщика теперь требуют завершённого дополнительного
расчёта после основного анализа. Они сначала проверяют связь полных ответов
и нативных отчётов с основной таблицей, затем повторяют дополнительный расчёт
и включают его в общий манифест архива. Вместе сохраняются исходные 1 140 задач,
разбиения, код, протокол, зависимости и все векторы из 10 000 значений.
Внутри скачанного архива команда `python source_family_replay.py` повторяет
аудит источников и каждый дополнительный интервал без доступа к репозиторию.
Сначала следует установить сохранённые зависимости публикации. Этот расчёт
дополняет проверку основных ответов и нативных результатов, описанную в архиве.
CLI также принимает явные `--selection` и `--control-gate` для переносимых путей.

Переносимость проверена на искусственных таблицах назначений обоих форматов,
отдельно от реального исследования. Она не означает, что большие серии уже
завершены или что их интервалы рассчитаны.

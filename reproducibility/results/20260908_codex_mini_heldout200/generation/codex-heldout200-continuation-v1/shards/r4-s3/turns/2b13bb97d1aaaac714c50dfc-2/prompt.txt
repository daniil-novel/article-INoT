## Proposed behavior

### Core flow
- Initialize two empty lists:
  - one for timestamps
  - one for random values
- Start a timer using `time.time()` or `datetime.now()`
- In a loop, continue generating points until the elapsed time reaches `duration`

  1. capture current time

  5. update the plot in real time
  6. sleep briefly to avoid a busy loop and control sampling rate

## Edge cases to handle

   - Should likely return empty lists immediately
   - Could still create an empty plot or skip plotting entirely

2. **Non-numeric `duration`**
   - If the caller passes a string or invalid type, the function should either:
     - raise a clear error, or
     - attempt conversion to float
   - Best practice: convert to `float` and let invalid values fail naturally with a clear exception

3. **Very short duration**
   - The loop may execute only once or not at all
   - The function should still return valid tuple/list structures

4. **Very long duration**
   - The lists may grow large
   - Plot updates can become slow, so `plt.pause(...)` should be small and the loop should not refresh too aggressively

5. **Plot backend unavailable**
   - In some environments, interactive plotting may not work
   - The function should still collect and return data even if plotting is limited

6. **Window closed by user**
   - If the plot window is closed during execution, data collection should ideally still continue or stop gracefully
   - At minimum, avoid crashing if plotting fails

7. **Timestamp collisions**

import time
from datetime import datetime
from random import randint
import matplotlib.pyplot as plt

def task_func(duration):
    duration = float(duration)
    if duration <= 0:
        return ([], [])

    timestamps = []
    values = []

    plt.ion()
    fig, ax = plt.subplots()
    line, = ax.plot([], [], marker='o', linewidth=1)
    ax.set_xlabel("Sample")
    ax.set_ylabel("Random value")
    ax.set_title("Real-time random data")

    start = time.time()
    try:
        while time.time() - start < duration:
            ts = datetime.now().strftime('%H:%M:%S.%f')
            value = randint(0, 100)

            timestamps.append(ts)
            values.append(value)

            try:
                x_data = list(range(len(values)))
                line.set_data(x_data, values)
                ax.relim()
                ax.autoscale_view()
                fig.canvas.draw_idle()
                plt.pause(0.05)
            except Exception:
                pass
    finally:
        try:
            plt.ioff()
            plt.close(fig)
        except Exception:
            pass

    return (timestamps, values)

## Edge cases to handle

### Missing/invalid columns
- If a column in `cols` is not present in `data`, ignore it or handle explicitly.
- Best behavior for robustness: skip missing columns rather than failing.

- Correlation cannot be computed on arbitrary strings/categories directly.

### Constant columns
- If a column has zero variance, correlation with any other column is undefined (`NaN`).
- Such pairs should be ignored.

### Missing values
- `pandas.Series.corr()` automatically handles pairwise missing data by aligning and ignoring `NaN`s.
- If too few overlapping values remain, result may still be `NaN`; skip those pairs.

### Duplicate column names in `cols`
- If `cols` contains duplicates, combinations may produce repeated work.
- Deduplicate `cols` while preserving order if needed.

### Threshold behavior
- The requirement says “greater than a certain threshold,” so use:

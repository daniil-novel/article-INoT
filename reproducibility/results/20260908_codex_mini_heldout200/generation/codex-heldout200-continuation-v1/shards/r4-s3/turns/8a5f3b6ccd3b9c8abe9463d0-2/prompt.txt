### Edge cases to handle
1. **Invalid `data` type**
   - If `data` is not JSON-serializable, `json.dump` will fail.
   - Examples: sets, custom objects without serialization support.

2. **Invalid filename**
   - Empty string, invalid path, or inaccessible directory.
   - File creation may fail due to permissions or bad path.

3. **File write failure**
   - Disk permission issues.
   - Path does not exist.
   - Locked file or unsupported filesystem behavior.

4. **Read-back failure**
   - File was not written correctly.
   - File contents are not valid JSON.
   - File encoding problems.

5. **Existence check failure**
   - Even if write seems successful, confirm with `os.path.exists`.
   - If false, return failure.

6. **Content mismatch**
   - The read-back object should match the original JSON structure.
   - Note that JSON converts some Python types:
     - tuples become lists
     - dictionary keys become strings if not already strings
   - Therefore exact Python object equality may not always hold if the input is not a plain JSON-compatible dict.

import json
import os

def task_func(filename, data):
    success = False
    written_data = None

    try:
        with open(filename, "w", encoding="utf-8") as f:
            json.dump(data, f, ensure_ascii=False)

        if not os.path.exists(filename):
            return False, None

        with open(filename, "r", encoding="utf-8") as f:
            written_data = json.load(f)

        success = True
    except Exception:
        success = False
        written_data = None

    return success, written_data

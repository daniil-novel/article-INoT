## Implementation Plan

### 1) Validate and normalize inputs
- Ensure `my_path` is treated as a directory path.
- Decide how to handle invalid inputs:
  - If `my_path` does not exist or is not a directory, raise an appropriate exception.
  - If `days_old` is negative, treat as invalid input and raise `ValueError`.

### 2) Prepare the archive directory
- Build the archive path as:
  - `os.path.join(my_path, "archive")`

### 3) Define the age threshold
- Compute current time with `time.time()`.
- Convert `days_old` into seconds:
  - `threshold_seconds = days_old * 24 * 60 * 60`
- A file is eligible for archiving if:
  - `current_time - os.path.getmtime(file_path) > threshold_seconds`

### 4) Find candidate files
- Search only within the given directory, not recursively unless explicitly required.
- Iterate over each extension in `FILE_EXTENSIONS`.
- Use `glob.glob` with a pattern like:
  - `os.path.join(my_path, f"*{ext}")`

### 5) Filter by age and move files

- Verify it is actually a file, not a directory.

- If yes:
  - Move it into the archive directory using `shutil.move`.
  - Preserve the filename.

### 6) Handle filename collisions in archive
- If a file with the same name already exists in `archive`, decide a collision strategy:
  - overwrite behavior depends on `shutil.move` and destination state.

  - If destination exists, rename the incoming file before moving, e.g. append timestamp or counter.

### 7) Return value
- Return the string path to the archive directory.
- Use the exact archive directory created under `my_path`.

## Edge Cases to Consider

- `my_path` does not exist.

- `days_old == 0`:

- `days_old < 0`:
  - Invalid input; should raise `ValueError`.
- Very large `days_old`:
  - No files may qualify, but function should still return archive path.

### File selection edge cases

- Hidden files like `.txt`-named edge cases are unlikely but should be considered.

### File modification time edge cases
- Files whose modification time is exactly equal to the threshold:
  - Decide whether to move on `>` or `>=`.
  - Requirement says “older than days_old,” so `>` is the clearest choice.
- Files modified in the future due to clock skew:
  - These should not be archived.

### Archive directory edge cases
- Existing `archive` folder already contains files.
- Some files may already have been archived previously.
- A file might be moved while the loop is iterating, so ensure the source list is collected before moving if needed.

### Robustness edge cases
- File becomes unavailable between globbing and moving.
- Non-regular files matching the glob pattern, such as symlinks or directories.
- Read-only source files; `shutil.move` may fail depending on platform and permissions.

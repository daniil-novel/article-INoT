## Important edge cases

1. **Less than 2 valid columns**
   - If fewer than two usable columns are provided, return an empty list.

2. **Missing column names**
   - If `cols` contains names not present in `data`, skip them or handle them safely.
   - Best behavior is usually to ignore missing columns rather than crash.

3. **Non-numeric columns**
   - Correlation on strings / categorical values will fail or produce meaningless results.
   - Filter to numeric columns before computing correlation.

4. **NaN values**
   - Pandas correlation methods ignore aligned missing values by default.
   - If a pair has too few overlapping non-NaN values, the correlation may be `NaN`; such pairs should be skipped.

5. **Constant columns**
   - A column with zero variance produces undefined correlation (`NaN`).
   - These pairs should not be included.

6. **Threshold boundary**
   - The prompt says “greater than a certain threshold,” so use `>` not `>=`.

7. **Duplicate column names in `cols`**
   - If duplicates appear, they may cause repeated pair generation.
   - Consider deduplicating `cols` first while preserving order.

8. **Order of pairs**
   - Since combinations are unordered, output pairs in the same order generated by `combinations`.
   - Example: `(A, B)` but not `(B, A)`.

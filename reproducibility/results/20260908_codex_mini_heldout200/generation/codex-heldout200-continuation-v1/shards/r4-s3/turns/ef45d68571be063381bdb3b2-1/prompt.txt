## Implementation plan

### 1) Validate / interpret inputs
- Treat `points_count` as the number of points to generate.

### 2) Generate points uniformly inside the circle
To ensure uniform distribution over area, do **not** choose radius uniformly. Instead:
- Sample angle `theta` uniformly from `[0, 2π)`.
- Sample `u` uniformly from `[0, 1)`.
- Convert to radial distance using `r = radius * sqrt(u)`.
- Convert to Cartesian coordinates:
  - `x = r * cos(theta)`
  - `y = r * sin(theta)`

This gives points uniformly distributed across the disk.

### 3) Collect coordinates
- Build two lists: `xs` and `ys`.
- Repeat the sampling process `points_count` times.
- Append each generated point to the lists.

### 4) Create the scatter plot
- Create a figure and axes with `plt.subplots()`.
- Plot points using `ax.scatter(xs, ys)`.
- Do not pass styling arguments, so the scatter plot remains at its default appearance.

### 5) Preserve circle proportions
- Call `ax.set_aspect('equal', adjustable='box')` or equivalent.
- This ensures the rendered shape is geometrically correct.

### 6) Return the Axes object
- Return the `Axes` instance, not the figure.

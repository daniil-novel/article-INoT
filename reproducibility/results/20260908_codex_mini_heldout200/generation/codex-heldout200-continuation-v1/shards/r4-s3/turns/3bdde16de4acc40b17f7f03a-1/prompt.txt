## Edge cases to handle

### `n = 0`
- No numbers are generated.
- Average is undefined.
- Recommended behavior:
  - return `[]` and `0`
  - plot an empty chart or skip plotting gracefully

### `n < 0`
- Invalid input.
- Recommended behavior:
  - raise `ValueError`

### Non-integer `n`
- Since the task says “generate `n` random numbers,” `n` should be an integer.
- Recommended behavior:
  - raise `TypeError` or `ValueError`

### `value` outside `[0, 1]`
- This is valid mathematically.
- If `value > 1`, count should be `0`.
- If `value <= 0`, count should be `n`.

### Duplicate numbers
- Random floats can still theoretically repeat.
- `bisect_left` handles duplicates correctly for the `>= value` count.

### Floating-point comparisons
- Comparing to the average is sensitive to floating-point precision.
- Use plain `>` as specified; no tolerance unless explicitly required.

### Very large `n`
- Sorting dominates with `O(n log n)`.
- The approach remains fine, but plotting very large datasets may be slow.

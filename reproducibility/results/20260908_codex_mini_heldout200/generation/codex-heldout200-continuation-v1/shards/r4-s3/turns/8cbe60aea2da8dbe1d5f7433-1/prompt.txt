Here’s an implementation plan for `task_func(json_data: str, key_path: list)`.

## Goal
- Parse a JSON string.
- Traverse the JSON object along `key_path`.
- Extract numeric values from the target node.
- Plot those values as a **boxplot**.
- Return a `matplotlib.figure.Figure`.

## Planned behavior

### 1) Validate and parse input JSON
- If `json_data` is empty or only whitespace, raise `ValueError`.
- Use `json.loads(json_data)` to parse.
- If parsing fails (`JSONDecodeError`), raise `ValueError` for corrupted JSON.

### 2) Traverse the JSON by `key_path`
- Start from the parsed root object.
- For each key in `key_path`:
  - Require the current object to be a `dict`.
  - If the key is missing, raise `KeyError`.
  - Move to `current = current[key]`.
- If `key_path` is empty:
  - Use the root object directly as the data source.

### 3) Extract numeric values
- Recursively collect numeric data from the target node.
- Accept:
  - `int`
  - `float`
- Exclude `bool` values explicitly, since `bool` is a subclass of `int` in Python.
- If the node is:
  - a list/tuple: recurse into elements
  - a dict: recurse into values
  - a scalar number: collect it
  - anything else: ignore it
- After collection:
  - If no numeric values were found, raise `ValueError`.

### 4) Create the boxplot
- Build a figure using `matplotlib`.
- Use either:
  - `plt.boxplot(values)`, or
  - `seaborn.boxplot(y=values)`
- Set a title/axis labels for clarity.
- Return the figure object.

---

## Edge cases to handle

### Input-related
- **Empty string / whitespace-only JSON**
  - Raise `ValueError`
- **Invalid JSON syntax**
  - Raise `ValueError`
- **`key_path` is not usable**
  - If the structure cannot be traversed as dicts, raise `KeyError` when a required key is missing or the path is invalid.

### Traversal-related
- **Missing key in the path**
  - Raise `KeyError`
- **Intermediate node is not a dict**
  - Raise `KeyError` because the specified path cannot continue
- **Empty `key_path`**
  - Treat the root JSON object as the target

### Data-related
- **No numeric data at target location**
  - Raise `ValueError`
- **Mixed types**
  - Extract only numeric entries, ignore non-numeric ones
- **Booleans in the data**
  - Do not treat `True`/`False` as numeric values
- **Nested lists/dicts**
  - Recursively search them for numbers
- **Single numeric value**
  - Still plot it; boxplot should work with one value
- **NaN / Infinity**
  - Best to exclude them from numeric data to avoid invalid plots

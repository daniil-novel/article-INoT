## Goal
Take a dictionary of numeric values, scale them to the range `[0, 1]` using `MinMaxScaler`, then plot the scaled results and return:

1. a `pandas.DataFrame` with the scaled data
2. a `matplotlib.axes.Axes` object for the plot

---

## Planned Approach

### 1. Validate and prepare input
- Accept `data_dict` as the input dictionary.
- Convert it into a `pandas.DataFrame`.
- Ensure values are in a format compatible with `MinMaxScaler`:
  - ideally numeric scalars or numeric lists/arrays
  - if the dictionary is simple like `{"a": 10, "b": 20}`, transform it into a one-column DataFrame
- Preserve keys as the index or as a column label, depending on the intended visualization style.

### 2. Apply MinMax scaling
- Instantiate `MinMaxScaler()`.
- Fit and transform the numeric data.
- Wrap the scaled result back into a `DataFrame` with:
  - the same index as the input
  - sensible column names copied from the original data

### 3. Plot the scaled data
- Create a plot using `matplotlib`.
- Since the output must be an `Axes`, use `fig, ax = plt.subplots()`.
- Plot the scaled values on the axes:
  - if there is one numeric series, use a line or bar plot
  - if there are multiple columns, plot each series on the same axes with a legend
- Set the plot title to `PLOT_TITLE`
- Label axes appropriately, e.g.:
  - x-axis: keys / samples
  - y-axis: scaled value

### 4. Return values
- Return:
  - the scaled `DataFrame`

## Edge Cases to Handle

### Empty input
- If `data_dict` is empty:
  - return an empty `DataFrame`
  - return an `Axes` object with the title set, but no plotted data

### Non-numeric values
- If values contain strings, `None`, or other non-numeric objects:
  - either raise a clear error
  - or convert where appropriate if the structure is predictable
- Since `MinMaxScaler` requires numeric input, invalid values should be rejected clearly.

### Constant values
- If all values in a column are identical:
  - `MinMaxScaler` will typically map them all to `0.0`
- Ensure the plot still renders correctly.

### Single value
- If only one element is present:
  - scaling should still work
  - the plot should not fail due to lack of multiple points

### Nested or irregular dict values
- If dictionary values are lists of different lengths or mixed shapes:
  - reject input or normalize it before scaling
- `MinMaxScaler` expects a consistent 2D numeric structure.

### Missing values (`NaN`)
- Decide whether to:
  - allow them and let scaling fail, or
  - fill/drop them before scaling
- For robustness, explicitly handle or reject them.

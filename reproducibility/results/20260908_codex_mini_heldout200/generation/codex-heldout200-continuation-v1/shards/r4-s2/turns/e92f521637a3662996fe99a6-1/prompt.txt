## Goal

## Proposed behavior

### 1) Build the DataFrame
- Use `pd.DataFrame(dictionary)`.
- This will treat dictionary keys as column names and list elements as row values.
- If lists are uneven, pandas will pad with `NaN`.

### 2) Locate matching values
- Compare the DataFrame to `item` elementwise.
- Collect all matches as tuples:
  - row index
  - column name
- Example result format:
  - `[(0, 2), (1, 1)]`

### 3) Frequency distribution
- While scanning matches, also count occurrences if needed.
- Since the required return value only includes positions and the DataFrame, this frequency information can be computed internally.
- If you want to expose it later, it could be:
  - total count of matches
  - count per column
  - count per row
- For the current task, the safest interpretation is to compute it internally but not change the return signature.

### 4) Optional sampling
- If `sample_size` is `None`, return all positions.
- If `sample_size` is provided:
  - sample from the full list of matched positions
  - if `random_seed` is not `None`, call `seed(random_seed)` before sampling
  - if `sample_size` is greater than the number of available positions, return all positions
  - if `sample_size` is `0`, return an empty list

Because only `randint` and `seed` are imported, sampling should be implemented manually:
- repeatedly choose a random index using `randint`

### Item not found
- Return:

### Unequal-length lists in dictionary values

- Those `NaN` cells should not be treated as matches unless `item` itself is a missing-value check

### Searching for `None` or `NaN`
- Special case may be needed because `NaN != NaN`
- Use `pd.isna(...)` if the target item is a missing value

### Invalid `sample_size`
- If negative or not an integer, raise a clear error
- If larger than the number of matches, cap it to the available number of positions

### Reproducibility
- Only apply `seed(random_seed)` when sampling is needed
- This ensures the same sampled positions across runs

## Important edge cases

### Directory issues
- `csv_dir` may not exist
  - should raise a clear error or let the natural `FileNotFoundError` occur
- `processed_dir` may not exist

### File content issues
- Empty CSV file
  - no match, skip
- Empty rows inside CSV
  - avoid index errors by checking `if row`
- Rows with no columns
  - treat as non-matching
- First cell may contain whitespace
  - decide whether to compare raw values or stripped values
  - safest for exact matching: compare raw values unless normalization is explicitly needed

### Multiple matches in one file
- Only the **first** matching row index should be recorded

### CSV formatting issues
- Files may contain commas, quoted fields, etc.
  - `csv.reader` handles normal CSV parsing
- Encoding issues
  - default text mode may fail on unusual encodings, but no special encoding is specified

### File naming
- Use the filename, not full path, as the dictionary key unless otherwise required

### Move conflicts
- If a file with the same name already exists in `processed_dir`, `shutil.move` may overwrite or error depending on platform/filesystem behavior
- If robustness is desired, handle name collisions explicitly

### Row indexing
- Clarify whether the index is **0-based**
  - The examples suggest normal Python indexing, so use `0`-based row indices unless instructed otherwise

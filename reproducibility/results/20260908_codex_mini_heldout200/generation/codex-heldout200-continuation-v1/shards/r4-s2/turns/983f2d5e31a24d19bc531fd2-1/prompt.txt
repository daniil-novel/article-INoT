### 2. Missing required columns

### 3. Non-datetime values

### 4. Missing closing prices
- Drop rows where the close price is missing.
- Ensure timestamps and prices stay aligned after filtering.

### 5. Unsorted timestamps
- Sort by date/time before fitting and plotting.
- This avoids incorrect trend fitting and broken plot order.

### 6. Too few points
- Linear regression technically works with very few points, but:
  - with only one valid point, the fitted model is meaningless
- Better to require at least 2 valid observations.

### 7. Constant prices
- If all closing prices are identical, regression will produce a flat line.
- This is valid and should still work.

### 8. Duplicate timestamps
- Duplicate dates may skew the fit.
- Either allow them, average duplicates, or drop duplicates.
- Simpler approach: keep them unless the data quality is a concern.

### 9. Timestamp overflow / scaling issues
- Raw Unix timestamps can be very large numbers.
- Linear regression can still work, but for numerical stability it may help to subtract the first timestamp and use elapsed seconds instead.
- If doing so, make sure future timestamps use the same offset.

### 10. Plot readability
- If the historical series is large, make sure predicted points are visually distinct.
- Use markers or dashed lines for forecasts.

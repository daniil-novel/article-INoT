## Goal
Implement a function that:

1. Accepts an HTTP request string.
2. Verifies that it is a valid `GET` request.
3. Extracts the requested filename/path.
4. Checks whether the file exists in the server directory.
5. Returns an HTTP response string:
   - `200 OK` with `Content-Length` and file content if found
   - an error response/message if the request is invalid or the file is missing

---

## Proposed approach

### 1) Validate input
- Ensure `request` is a non-empty string.
- If not, return a `400 Bad Request` response.

### 2) Parse the HTTP request line
- Use the first line of the request only.
- Expected format is something like:
  - `GET /filename HTTP/1.1`
- Split the request into lines, then parse the request line with a regex or string split.
- Extract:
  - HTTP method
  - target path
  - HTTP version

### 3) Check request validity
- Method must be `GET`.
- Path must be present and not empty.
- If the request line does not match the expected structure, return `400 Bad Request`.

### 4) Extract the filename safely
- Remove the leading `/` from the path if present.
- Reject paths that could escape the server directory, such as:
  - `../secret.txt`
  - `/etc/passwd`
  - paths containing `..`
- Prefer a safe normalized path check using `os.path.normpath`.
- If the resulting path is invalid or empty, return `400 Bad Request`.

### 5) Check file existence
- Treat the current working directory or server directory as the file root.
- Use `os.path.exists` and `os.path.isfile`.
- If the file does not exist or is not a regular file, return `404 Not Found`.

### 6) Read file contents
- Open the file and read its contents.
- Since the response must be a string, read in text mode.
- If file reading fails unexpectedly, return `500 Internal Server Error`.

### 7) Build the HTTP response
For success:
- Return a response string with:
  - status line: `HTTP/1.1 200 OK`
  - `Content-Length: <length>`
  - blank line
  - file content

For errors:
- Return a response string with:
  - appropriate status line
  - blank line
  - human-readable error message
- The prompt only explicitly requires `Content-Length` for `200 OK`, so it can be omitted from error responses unless you want consistency.

import re
import os

def task_func(request):
    def response(status_line, body="", include_length=False, content_length=0):
        lines = [f"HTTP/1.1 {status_line}"]
        if include_length:
            lines.append(f"Content-Length: {content_length}")
        return "\n".join(lines) + "\n\n" + body

    if not isinstance(request, str) or not request.strip():
        return response("400 Bad Request", "Invalid request")

    request_line = request.splitlines()[0].strip()
    match = re.fullmatch(r"GET\s+(\S+)\s+HTTP/\d+\.\d+", request_line)
    if not match:
        return response("400 Bad Request", "Invalid request")

    raw_path = match.group(1)
    if not raw_path:
        return response("400 Bad Request", "Invalid request")

    # Remove query/fragment parts if present.
    raw_path = raw_path.split("?", 1)[0].split("#", 1)[0]

    # Convert request target to a relative filesystem path.
    relative_path = raw_path.lstrip("/")
    if not relative_path:
        return response("400 Bad Request", "Invalid request")

    normalized_path = os.path.normpath(relative_path)
    if normalized_path in ("", ".") or normalized_path.startswith("..") or os.path.isabs(normalized_path):
        return response("400 Bad Request", "Invalid request")

    root_dir = os.path.abspath(os.getcwd())
    file_path = os.path.abspath(os.path.join(root_dir, normalized_path))

    try:
        if os.path.commonpath([root_dir, file_path]) != root_dir:
            return response("400 Bad Request", "Invalid request")
    except ValueError:
        return response("400 Bad Request", "Invalid request")

    if not os.path.isfile(file_path):
        return response("404 Not Found", "File not found")

    try:
        with open(file_path, "rb") as f:
            data = f.read()
        try:
            content = data.decode("utf-8")
        except UnicodeDecodeError:
            content = data.decode("latin-1")
    except OSError:
        return response("500 Internal Server Error", "Internal server error")

    return response("200 OK", content, include_length=True, content_length=len(data))

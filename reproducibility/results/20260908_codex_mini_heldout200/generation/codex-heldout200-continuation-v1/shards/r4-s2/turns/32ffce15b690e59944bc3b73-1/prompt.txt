### Inputs
- `target_value='332'`: value to match against the **first cell** of each row.
- `csv_dir='./csv_files/'`: directory to scan.
- `processed_dir='./processed_files/'`: destination for moved files.
- `simulate=False`: if `True`, skip actual file moves.

### Output
- `result` (dict): maps each CSV filename to the row index where the first match was found.
- Row index should be **zero-based** unless the task explicitly requires otherwise. The example indices `10` and `15` fit standard Python indexing.

### 2. Validate or prepare directories

   - If matched:
     - store `result[filename] = row_index`

## Edge cases to handle

### File/content edge cases
- **Empty CSV file**: no rows, so no match.
- **Blank rows**: skip them safely.
- **Rows with no columns**: avoid `IndexError` by checking `if row`.
- **First cell missing**: same as above.
- **Multiple occurrences in one file**: only the first match should be recorded.
- **Exact matching**: compare values exactly; do not accidentally match partial values like `"3321"`.

### Directory/file edge cases
- **No CSV files in directory**: return `{}`.
- **`csv_dir` does not exist**: handle gracefully, likely returning `{}`.
- **`processed_dir` missing**: create it when moving is enabled.
- **Destination file already exists**: decide on behavior in implementation:
  - either let `shutil.move` handle it,
  - or pre-handle collisions by renaming/overwriting.
- **CSV files with uppercase extension** like `.CSV`: include them if using case-insensitive filtering.
- **Non-CSV files** in the directory: ignore them.

### Data/format edge cases
- **Whitespace in the first cell**:
  - If strict matching is required, compare exactly as-is.
  - If data is messy, you may choose to normalize with `.strip()`, but that changes semantics; only do this if intended.
- **Encoding issues**:
  - Use a sensible default such as UTF-8.
  - If the dataset may contain BOM, `utf-8-sig` can be helpful.

## Recommended design choices
- Use **zero-based row indexing**.
- Return only files where a match is found.
- Keep file scanning and moving logically separate:
  - scan first,
  - then move if applicable.
- Make output deterministic by sorting filenames.

## Goal
Create a function that:
- accepts a list of comma-separated strings,
- randomly applies one of four operations to the substrings in each string:
  - `remove`
  - `replace`
  - `shuffle`
  - `randomize`
- returns a `pd.DataFrame` with:
  - `Original String`
  - `Modified String`

---

## Implementation Plan

### 1. Initialize randomness
- If `seed` is provided, call `random.seed(seed)` so results are reproducible.
- If `seed` is `None`, keep normal random behavior.

---

### 2. Process each input string independently
For each string in `data_list`:
1. Keep the original string unchanged for the output column `Original String`.
2. Split the string by commas:
   - Use `split(',')`
   - Do **not** strip whitespace, because whitespace is part of the substring identity.
3. The resulting list is the set of substrings to operate on.

---

### 3. Choose a random operation
Randomly select one of:
- `remove`
- `replace`
- `shuffle`
- `randomize`

Important rule:
- If the string has only one substring, `remove` must not be applied.
  - In that case, choose from `replace`, `shuffle`, `randomize` only.

---

### 4. Apply the selected operation

#### A. Remove
- Randomly select one substring index.
- Remove that substring from the list.
- Join the remaining substrings back with commas.

#### B. Replace
- Randomly select one substring index.
- Replace that substring with the literal string `'random_string'`.
- Join back with commas.

#### C. Shuffle
- Randomly reorder the substrings in place or via a copied list.
- Join back with commas.

#### D. Randomize
- The requirement says “assigns a new, random order to the substrings.”
- This is effectively the same as `shuffle` in output behavior.
- Implement it as a separate randomly permuted ordering, for example by:
  - creating a shuffled copy of the substring list,
  - or generating a random permutation of indices.
- The important part is that the output order differs randomly from the original.

---

### 5. Build output rows
For each input string, store:
- `Original String`: original input string
- `Modified String`: transformed string after the selected operation

---

### 6. Return a DataFrame
Construct and return a `pd.DataFrame` from the collected rows with exactly these columns:
- `Original String`
- `Modified String`

## Edge Cases to Handle

### 1. Empty string input
Example: `""`
- Splitting yields `[""]`.
- Since there is only one substring, `remove` should not be used.
- `replace` would change it to `"random_string"`.
- `shuffle` and `randomize` would leave it effectively unchanged.

### 2. Single-substring strings
Example: `"apple"`
- No `remove`.
- `replace` -> `"random_string"`
- `shuffle` / `randomize` -> unchanged, since only one item exists.

### 3. Strings with spaces around items
Example: `"apple, banana,Cherry"`
- Spaces must be preserved as part of the substring values.
- Do not trim before processing.

### 4. Duplicate substrings
Example: `"a,a,a"`
- Operations should still work correctly.
- Selection should be by position, not by value.

### 5. Case sensitivity
Example: `"Apple,apple"`
- Treat them as distinct substrings where relevant.
- No normalization should be applied.

### 6. Consecutive commas
Example: `"a,,b"`
- Splitting yields `["a", "", "b"]`.
- Empty substrings are valid and should be preserved and processed like any other substring.

### 7. Leading/trailing commas
Examples:
- `",a,b"`
- `"a,b,"`
- These produce empty substrings at the ends and should be preserved.

### 8. Very short strings
- If a string has only one valid substring, make sure `remove` is never selected.
- Ensure index selection always uses the current list length.

### 9. Randomize vs shuffle overlap
- Since both mean reordering substrings randomly, they may produce the same kind of output.
- That is acceptable unless a stricter distinction is required.

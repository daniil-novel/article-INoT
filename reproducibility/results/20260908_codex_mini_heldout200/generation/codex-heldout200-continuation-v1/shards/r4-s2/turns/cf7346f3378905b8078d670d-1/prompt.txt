Return `None` if:

### Implementation plan

1. **Validate input early**
   - Check whether `url` is missing, `None`, or empty after stripping whitespace.
   - If invalid, return `None` immediately.

2. **Send HTTP request**
   - Use `requests.get(url)` to fetch the page.
   - Optionally include a timeout to avoid hanging indefinitely.
   - Catch `requests.RequestException` and return `None`.

3. **Check HTTP status**
   - If `response.status_code != 200`, return `None`.
   - Do not attempt to decode or parse unsuccessful responses.

4. **Decode response content**
   - Decode `response.content` with the supplied `from_encoding`.
   - Catch decoding-related exceptions:
     - `UnicodeDecodeError`
     - `LookupError` for unknown encodings
     - `TypeError` if the encoding value is invalid
   - Return `None` on decode failure.

5. **Parse HTML**
   - Choose parser:
     - `"lxml"` if `use_lxml` is `True`
     - `"html.parser"` otherwise
   - Create `BeautifulSoup(decoded_html, parser)`.
   - If parsing raises an exception, return `None`.

6. **Return result**
   - On success, return the `BeautifulSoup` object.

### Edge cases to consider

- **`url=None`**
  - Must return `None`, not raise an error.

- **Empty string / whitespace-only URL**
  - Treat as invalid and return `None`.

- **Malformed URL**
  - `requests` may raise an exception; catch and return `None`.

- **DNS / connection / timeout failures**
  - Catch all request exceptions and return `None`.

- **HTTP errors like 403 / 404 / 500**
  - Even if a response exists, status not equal to `200` means return `None`.

- **Unsupported or wrong encoding name**
  - `decode()` can fail with `LookupError`; return `None`.

- **Encoding mismatch**
  - If bytes cannot be decoded with the specified encoding, return `None`.

- **Invalid parser choice**
  - If `use_lxml=True` but `lxml` is unavailable, BeautifulSoup may fail; return `None`.

- **Non-HTML content**
  - BeautifulSoup can often still parse it, but if parsing raises unexpectedly, return `None`.

- **Unexpected exceptions**
  - To satisfy the “any failure returns `None`” requirement, use a broad safety net around the full fetch/decode/parse process.

- Should still create `hashes.json`.

- Should not be included in the hash list.

### Nested subdirectories
- Must be traversed recursively and included.

### Large files
- Must be hashed in chunks to avoid memory issues.

### Non-regular files
- Skip symlinks, sockets, pipes, etc. unless explicitly needed.
- Safer to hash only regular files.

### Deterministic output

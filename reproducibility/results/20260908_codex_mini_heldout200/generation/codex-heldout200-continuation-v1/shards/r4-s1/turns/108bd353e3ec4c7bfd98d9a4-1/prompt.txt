### 3) Non-numeric values

- strings

- lists
- `None`

Recommended: skip them or raise a clear error.
- If robustness is preferred, skip invalid values and continue
- If strictness is preferred, raise `TypeError`

### 4) Mixed numeric types
- `int`, `float`, and NumPy numeric values should work fine
- Values can be converted to `float` or passed directly to NumPy

### 5) Single value for a key
- mean and median are both that value

### 6) No valid numeric values for a key
- return `np.nan` for both stats
- still create a corresponding plot, or skip the plot if you want to avoid empty visuals
- the requirement suggests one plot per key, so keeping the plot is better

### 7) Large numbers / precision
- NumPy handles them well, but floating-point output may include decimals even for whole-number inputs

### 8) Duplicate keys across dictionaries
- expected and handled by aggregation

### 9) Invalid top-level JSON structure
- if the file contains an object instead of a list, or non-dict list items, raise an error

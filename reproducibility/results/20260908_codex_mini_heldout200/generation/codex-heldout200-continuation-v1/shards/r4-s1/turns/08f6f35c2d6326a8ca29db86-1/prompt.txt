## Goal
Return a `pandas.DataFrame` with:

- `Word`: all whitespace-separated tokens that start with `$`
- `Frequency`: how many times each such token appears

Also:

- raise `ValueError` if `text` is not a string
- ignore tokens that are made entirely of punctuation, even if they start with `$`

---

## Plan

### 1) Validate input
- Check `isinstance(text, str)`.
- If not, raise `ValueError`.

### 2) Split the text into whitespace-separated tokens
- Use `text.split()` so tokens are separated by any whitespace:
  - spaces
  - tabs
  - newlines
  - repeated whitespace

### 3) Filter valid `$`-prefixed words
For each token:
- keep it only if it starts with `$`
- ignore it if it is composed entirely of punctuation characters

A practical rule:
- `token.startswith('$')`
- and `not all(ch in punctuation for ch in token)`

This makes sure:
- `$hello` is counted
- `$test!` is counted
- `$!!!` is ignored
- `$` is ignored

### 4) Count occurrences
- Use a dictionary or `collections.Counter` to count valid tokens.
- Preserve first-seen order if you want to match the example output style.

### 5) Build the DataFrame
- Create a `pd.DataFrame` with two columns:
  - `Word`
  - `Frequency`
- Each row corresponds to one distinct valid `$` word and its count.

### 6) Return the DataFrame
- Return the final `pd.DataFrame`.

## Edge cases to handle

1. **Non-string input**
   - `None`, numbers, lists, etc. → raise `ValueError`

2. **Empty string**
   - Return an empty DataFrame with columns `Word` and `Frequency`

3. **Multiple spaces / tabs / newlines**
   - `split()` should handle them correctly

4. **Tokens made only of punctuation**
   - Examples: `$`, `$!!!`, `$$$`
   - These should be ignored

5. **Mixed tokens**
   - Examples: `$a!`, `$1`, `$hello,`
   - These should be counted because they are not entirely punctuation

6. **Case sensitivity**
   - `$Hello` and `$hello` should be treated as different words unless the task explicitly says otherwise

7. **Ordering**
   - If no sorting is specified, keeping first appearance order is reasonable and matches the sample

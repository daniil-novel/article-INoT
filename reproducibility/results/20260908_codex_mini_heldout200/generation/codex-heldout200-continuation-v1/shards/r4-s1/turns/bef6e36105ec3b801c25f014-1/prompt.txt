## Goal
Create a function that:
1. Takes a pandas DataFrame and two column names.
2. Draws a scatter plot of `x_column` vs `y_column`.
3. Fits a linear regression model to the same data.
4. Overlays the predicted regression line in red on the same Axes.
5. Returns the `matplotlib.axes._axes.Axes` object.

---

## Planned behavior

### 1) Validate inputs
- Confirm the specified columns exist in `df`.
- Extract the two columns.
- Ensure the selected data can be used numerically by `LinearRegression`.

### 2) Clean / prepare data
- Use only the two required columns.
- Handle missing values by dropping rows where either x or y is missing.
- Convert x data into the 2D shape expected by scikit-learn:
  - `X = df[[x_column]].values`
  - `y = df[y_column].values`

### 3) Create scatter plot
- Create a Matplotlib figure/axes with `plt.subplots()`.
- Plot the scatter points using `ax.scatter(...)`.

### 4) Fit linear regression
- Instantiate `LinearRegression()`.
- Fit the model on `X` and `y`.

### 5) Plot regression line
- Generate x-values for the line.
  - Usually sort the x-values or create an evenly spaced grid from min to max.
- Predict y-values using the fitted model.
- Plot the line on the same axes in red:
  - `ax.plot(x_line, y_pred, color='red')`

### 6) Return result
- Return the `Axes` object.

---

## Important edge cases to handle

### Missing columns
- If `x_column` or `y_column` is not in `df.columns`, raise a clear error, such as `KeyError` or `ValueError`.

### Missing values
- Drop rows with `NaN` in either column before fitting or plotting.
- If too many rows are missing and fewer than 2 valid points remain, fitting is not meaningful.

### Non-numeric data
- If either column contains strings or mixed types that cannot be converted to numeric, raise a clear error.
- Optionally, attempt conversion to numeric and fail early if conversion is impossible.

### Constant x-values
- If all `x_column` values are identical, linear regression can still return a horizontal fit, but the plot line will be vertical in x-space only as points share one x-value.
- For plotting, if all x are the same, use that constant x for the line and predicted y values, or simply plot the fitted predictions over the same x-values.

### Very small datasets
- With only one valid point, regression cannot be meaningfully fit.
- Best behavior: raise a `ValueError` explaining that at least 2 valid rows are required.

### Empty DataFrame after cleaning
- If all rows are dropped due to missing values, raise a clear error.

### Unsorted x-values
- If plotting the regression line using the original x order, the line may zig-zag.
- Better to sort x or create a smooth grid from min to max before plotting.

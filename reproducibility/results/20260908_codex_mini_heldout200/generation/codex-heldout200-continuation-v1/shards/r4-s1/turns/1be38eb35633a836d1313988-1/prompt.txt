## Goal
Create a function that:

1. Takes a pandas DataFrame and two column names.
2. Draws a scatter plot of `x_column` vs `y_column`.
3. Fits a `LinearRegression` model to the data.
4. Overlays the predicted regression line in **red** on the same Axes.
5. Returns the `matplotlib.axes._axes.Axes` object.

---

## Implementation Plan

### 1. Validate and extract the data
- Read the two specified columns from `df`.
- Keep only the rows where both columns are valid for modeling.
- Convert the selected columns to numeric values if needed, or rely on pandas/numpy compatibility if the data are already numeric.

### 2. Handle missing data
- Drop rows where either `x_column` or `y_column` is missing (`NaN`).
- If no valid rows remain after cleaning, the function should fail clearly or avoid fitting/plotting.

### 3. Prepare inputs for scikit-learn
- Reshape the x data into a 2D array of shape `(n_samples, 1)` because `LinearRegression` expects a 2D feature matrix.
- Keep y as a 1D target array.

### 4. Plot the scatter points
- Create or reuse a Matplotlib Axes object.
- Plot the data as a scatter plot on that Axes.

### 5. Fit the linear regression model
- Instantiate `LinearRegression`.
- Fit it using the cleaned x and y data.

### 6. Compute predictions for the regression line
- Use the x-values to generate prediction points.
- Best practice: sort x values or create an evenly spaced grid from `min(x)` to `max(x)` so the regression line appears smooth and left-to-right.
- Predict y-values for those x points using the fitted model.

### 7. Overlay the regression line
- Plot the predicted line in **red** on the same Axes.
- Ensure it is drawn after the scatter plot so it appears on top.

### 8. Return the Axes object
- Return the Axes containing both the scatter plot and the regression line.

## Important Edge Cases

### Missing columns
- If `x_column` or `y_column` does not exist in `df`, the function should raise an informative error.

### Empty or invalid data
- If the DataFrame is empty, or all selected rows are invalid after dropping missing values, fitting should not proceed.

### Non-numeric values
- Linear regression requires numeric inputs.
- If the columns contain strings or mixed types that cannot be converted, the function should either:
  - raise an error naturally, or
  - explicitly validate/convert and report a clear message.

### Constant x values
- If all x values are identical, the regression line is still definable mathematically, but the visual result may be degenerate or uninformative.
- The function should still handle this case without crashing.

### Too few points
- If there is only one valid data point, `LinearRegression` cannot meaningfully fit a line.
- The function should either raise a clear error or rely on sklearn to signal the problem.

### Existing axes state
- If the function uses the current Axes, it will overlay onto whatever plot is active.
- If it creates a new Axes, it should still return it cleanly.
- Since the requirement says “same Axes,” it is safest to plot both items on one Axes object.

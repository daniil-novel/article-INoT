## Plan

1. **Validate the input column**
   - Check that `column` exists in `df`.
   - If missing, raise a clear `KeyError` or `ValueError`.

2. **Extract and clean the data**
   - Take the selected series: `data = df[column]`.
   - Remove missing values with `dropna()`.
   - Convert to a NumPy array of numeric values.
   - If any non-numeric values are present and cannot be interpreted as numbers, either:
     - let the fitting step fail naturally, or
     - explicitly coerce to numeric and drop invalid values if allowed by the intended behavior.

3. **Handle empty data**
   - If no valid values remain after cleaning, raise a `ValueError` explaining that the column has no valid numeric data.

4. **Fit a normal distribution**
   - Use `mu, sigma = norm.fit(data)` to estimate the normal parameters.
   - This gives the mean and standard deviation of the best-fit normal curve.

5. **Create the histogram**
   - Create a matplotlib figure and axes with `plt.subplots()`.
   - Plot the histogram on the axes using:
     - `ax.hist(data, bins=bins, density=density, alpha=alpha, color=color)`
   - `density=True` ensures the histogram is scaled so the normal curve is comparable.

6. **Overlay the fitted normal curve**
   - Compute an x-grid spanning the data range, e.g.:
     - `xmin, xmax = data.min(), data.max()`
     - `x = np.linspace(xmin, xmax, 200)`
   - Evaluate the fitted normal density:
     - `y = norm.pdf(x, mu, sigma)`
   - Plot the curve with `ax.plot(x, y, ...)`.
   - Use a contrasting style, e.g. red line with label like `"Fitted normal"`.

7. **Add plot decorations**
   - Set title, x-label, and y-label.
   - Add a legend.
   - Optionally add a grid for readability.

8. **Return the Axes object**
   - Return the `ax` instance, not the figure.

## Important edge cases

1. **Missing column**
   - Should fail clearly with an informative exception.

2. **All values missing / empty after cleaning**
   - Cannot fit or plot meaningfully.
   - Raise `ValueError`.

3. **Constant data / zero variance**
   - `sigma` may be `0`, making `norm.pdf` invalid or degenerate.
   - In this case:
     - still plot the histogram,
     - skip the normal curve or draw a vertical line at the constant value,
     - optionally warn or annotate that the normal fit is degenerate.

4. **Non-numeric values**
   - If the column contains strings or mixed types, fitting may fail.
   - Decide whether to:
     - reject non-numeric input with a clear error, or
     - coerce to numeric and discard invalid entries.

5. **Very small datasets**
   - For one or two points, the fitted curve may be misleading.
   - Plotting should still not crash.

6. **Histogram scaling mismatch**
   - The normal curve should only be overlaid correctly when `density=True`.
   - If `density=False`, the normal PDF should be rescaled to histogram counts if you want visual alignment; otherwise, the curve will appear on a different scale.
   - A robust implementation can either:
     - always use `density=True`, or
     - rescale the curve by `len(data) * bin_width` when `density=False`.

7. **Unused `seed` parameter**
   - Since histogram fitting is deterministic, `seed` is not strictly needed.
   - It can be accepted for API compatibility without affecting behavior.

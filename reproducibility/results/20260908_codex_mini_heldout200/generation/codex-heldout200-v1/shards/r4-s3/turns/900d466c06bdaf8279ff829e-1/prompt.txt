  - `row_maxima = np.max(matrix, axis=1)`

## Edge cases to handle

### Empty input
- If `matrix` has no rows or no elements:
  - skewness/kurtosis are undefined
  - histogram is meaningless
- Decide whether to raise an exception or return `nan` values with an empty plot.
- Most robust behavior: raise a clear `ValueError` for empty input.

### Single row
- If the matrix has only one row:
  - row maxima is a 1-element array
  - skewness and kurtosis are undefined or may return `nan`
- This is acceptable if documented, but results may be `nan`.

### Single column
- Row maxima are simply the row values themselves.
- No special handling needed.

### Constant row maxima
- If all row maxima are identical:
  - standard deviation is zero
  - skewness and kurtosis are not informative and often become `nan`
- This should be expected behavior.

### NaN / inf values
- If the matrix contains `NaN` or `inf`:
  - `np.max` may propagate issues
  - `stats.skew` / `stats.kurtosis` may return `nan`
- If robustness matters, decide whether to:
  - reject non-finite values
  - or use `np.nanmax` and filter finite maxima before statistics

### Non-2D or ragged input
- If input is not rectangular or not matrix-like:
  - converting to `np.asarray` may produce an object array
- Best to validate shape and raise an error if it is not 2D numeric data.

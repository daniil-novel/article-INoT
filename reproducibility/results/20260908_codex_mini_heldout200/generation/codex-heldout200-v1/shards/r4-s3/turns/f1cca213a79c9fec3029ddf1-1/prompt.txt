- `MIN_WORDS <= len(sentence.split()) <= MAX_WORDS`

2. **Choose a random target length**
   - Pick `n = random.randint(MIN_WORDS, MAX_WORDS)`.

     - Mirror them in reverse order.
   - For an **odd-length** sentence:
     - Generate `n // 2` random words.
     - Choose one random middle word.
     - Mirror the first half around the middle word.

   - For each required position, randomly choose a word from `WORDS_POOL`.
   - Use `random.choice(WORDS_POOL)` for each slot.

5. **Assemble the sentence**

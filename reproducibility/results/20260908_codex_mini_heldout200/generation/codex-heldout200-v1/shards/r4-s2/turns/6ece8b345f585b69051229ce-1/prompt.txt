## Goal
- Accept a **base64-encoded JSON string** in `raw_string`
- Decode it, parse the JSON
- Save the data into a **CSV file**
- Return the **file path** as a string

---

## Planned behavior

### 1) Prepare the output path
- Ensure `output_dir` exists; create it if needed.
- Build a full file path using `os.path.join(output_dir, filename)`.
- If `filename` does not already end with `.csv`, optionally append `.csv` to make the result explicit.

---

### 2) Decode the base64 input
- Convert `raw_string` from base64 into bytes.
- Decode bytes into a UTF-8 string.
- If decoding fails, raise a clear error indicating invalid base64 input.

---

### 3) Parse the JSON
- Load the decoded string with `json.loads(...)`.
- The parsed value may be:
  - a `dict`
  - a `list`
  - or another JSON type, though CSV conversion is usually meaningful for dict/list structures

---

### 4) Convert parsed JSON to CSV
Handle common JSON shapes:

#### If the JSON is a list of dictionaries
- Use the keys from the first item (or the union of keys across items) as CSV headers.
- Write one row per dictionary.
- Missing fields should become empty values.

#### If the JSON is a single dictionary
- Write a CSV with two columns:
  - `key`
  - `value`
- For nested values, convert them to JSON strings before writing.

#### If the JSON is a list of scalar values
- Write a CSV with one column, e.g. `value`.

#### For nested dict/list values inside records
- Serialize nested objects using `json.dumps(...)` so they can be stored in a CSV cell.

---

### 5) Write the CSV file
- Open the target file with `newline=''` and UTF-8 encoding.
- Use `csv.writer` or `csv.DictWriter` depending on JSON shape.
- Write headers first when needed.
- Write all rows safely.

---

### 6) Return the file path
- Return the final path string after writing succeeds.

---

## Edge cases to handle

### Input validation
- `raw_string` is empty or not a valid base64 string
- decoded content is not valid UTF-8
- decoded content is not valid JSON

### JSON shape issues
- JSON is a scalar value like a number/string/boolean/null
- JSON is an empty list
- JSON is an empty dict
- JSON list contains mixed types, not all dictionaries
- dictionary keys differ across list items
- nested objects or arrays appear in fields

### File/path issues
- `output_dir` does not exist
- `filename` is empty
- `filename` already includes or omits `.csv`
- path contains invalid characters for the OS
- existing file should be overwritten or handled consistently

### CSV-specific issues
- Values contain commas, quotes, or newlines
- Unicode characters in data
- `None` values need consistent representation
- Nested structures need string conversion to avoid CSV writer errors

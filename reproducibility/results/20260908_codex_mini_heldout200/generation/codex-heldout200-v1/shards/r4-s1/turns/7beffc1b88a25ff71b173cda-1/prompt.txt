## Requirements interpretation
- Input: two lists `a` and `b`, plus an optional `items` list defaulting to `['apple', 'banana']`.
- Task: combine `a` and `b`, then count how often each predefined item appears in the combined list.
- Output: a `matplotlib.axes.Axes` object containing a bar chart of those frequencies.
- The chart should include one bar per item in `items`, in that order.

## Planned implementation
1. **Combine the two lists**
   - Use `itertools.chain(a, b)` or simple concatenation `a + b`.
   - `itertools.chain` is robust and works even if inputs are other iterables.

2. **Count frequencies**
   - Build a `collections.Counter` from the combined values.
   - Extract counts only for the predefined `items` list, preserving its order.

3. **Create the bar chart**
   - Use `fig, ax = plt.subplots()`.
   - Plot bars with:
     - x-axis labels: the predefined `items`
     - heights: corresponding counts
   - Optionally add axis labels and a title for clarity.

4. **Return the Axes**
   - Return `ax`, not the figure, to match the required output type.

## Edge cases to handle
- **Empty input lists**: the chart should still render with zero counts for all predefined items.
- **Items not present in the combined list**: count should be `0`.
- **Repeated items in `items` parameter**: decide whether to preserve duplicates or deduplicate.
  - Safer default: preserve input order as given, but duplicates would create repeated bars.
  - If uniqueness is desired, convert to an ordered unique list before plotting.
- **Non-string or mixed-type list entries**: `Counter` handles them, but bar labels should ideally be strings.
- **`a` or `b` being `None`**: if not explicitly guarded, `itertools.chain` will fail; if robustness is desired, treat `None` as an empty list.
- **Empty `items` list**: return an empty chart/axes with no bars.
- **Case sensitivity**: counting should be exact match unless normalization is explicitly requested.

## Suggested behavior choice
- Count exact matches only.
- Preserve the order of `items`.
- Treat missing item counts as zero.
- Return the `Axes` object after plotting.

## Goal
Compress every file in `src_folder` using the `gzip` command in a background process, then place the compressed `.gz` files into `dst_folder`. Return a dictionary with:

- `success`: `True` only if every eligible file was compressed and moved successfully
- `message`: human-readable summary
- `failed_files`: list of filenames that failed at any step

---

## Implementation plan

### 1) Validate inputs and prepare folders
- Check that `src_folder` exists and is a directory.
- Create `dst_folder` if it does not exist.
- If `src_folder == dst_folder`, decide whether to allow it:
  - Best approach: allow it only if compressed files are written with a temporary name or direct `.gz` output, to avoid conflicts.
  - Otherwise, treat it as a risky case and manage carefully.

### 2) Collect files to process
- Use `glob` to enumerate entries in `src_folder`.
- Filter to **regular files only**:
  - skip directories
  - skip symlinks if desired, or handle them explicitly
  - skip hidden/system files only if business rules require it; otherwise process them too
- Exclude already-compressed `.gz` files if you do not want double compression.
  - If not excluded, they will be recompressed, which is usually undesirable.

### 3) Compress each file via `gzip` in a background subprocess
For each source file:
- Construct destination `.gz` filename using the base file name, e.g.:
  - `report.txt` → `report.txt.gz`
- Run `gzip` as a background process using `subprocess.Popen`.
- Prefer a safe pattern such as:
  - `gzip -c <source_file>` to write compressed bytes to stdout
  - redirect stdout to the destination `.gz` file
- Wait for the process to complete:
  - capture return code
  - if non-zero, mark file as failed
- After successful compression, move or place the `.gz` file into `dst_folder`
  - if you already wrote it directly to destination, the “move” step is effectively satisfied
  - if you wrote to a temp file first, then use `shutil.move`

### 4) Handle failures per file without stopping the whole job
- If one file fails, continue processing the rest.
- Record the filename in `failed_files`.
- Typical failure points:
  - gzip command not found
  - permission denied
  - unreadable source file
  - destination cannot be written
  - file already exists and cannot be overwritten safely
  - subprocess exits with an error

### 5) Build the return dictionary
After processing all files:
- `success = len(failed_files) == 0`
- `message` should summarize:
  - total files found
  - how many succeeded
  - how many failed
- `failed_files` should contain only filenames that could not be compressed/moved

## Recommended behavior details

### Naming of compressed files
- Use the original basename plus `.gz`
  - Example: `a.txt` → `a.txt.gz`
- Ensure name collisions are handled:
  - if `dst_folder/a.txt.gz` already exists, either overwrite intentionally or mark as failed
  - safest default: do **not** overwrite silently unless explicitly desired

### Background process semantics
- “Executed as a background process using the `gzip` command” can be implemented with `subprocess.Popen`.
- Even though `Popen` starts a background process, you should still wait for completion before returning the final result, otherwise the function can’t know whether compression succeeded.
- So the process is background-launched, then synchronized with `wait()` / `communicate()`.

### Moving vs writing directly to destination
Two valid patterns:
1. **Direct-to-destination**
   - `gzip -c source > destination.gz`
   - simplest
   - no separate move step needed
2. **Temp then move**
   - compress to temp file
   - `shutil.move(temp, dst_folder)`
   - closer to literal “compress and move”

Either is acceptable; direct-to-destination is simpler and less error-prone.

## Edge cases to handle

1. **Empty source folder**
   - Return `success=True`
   - Message: “No files to compress”
   - `failed_files=[]`

2. **Source folder does not exist**
   - Return `success=False`
   - Include clear message
   - Add a generic failure entry only if you want to track that as a pseudo-file; otherwise keep `failed_files=[]`

3. **Destination folder does not exist**
   - Create it automatically

4. **Non-file entries in source**
   - Skip directories and other non-regular entries

5. **Unreadable file**
   - Mark as failed, continue with others

6. **`gzip` unavailable**
   - All files will fail
   - Message should clearly state gzip command could not be executed

7. **File already compressed (`.gz`)**
   - Decide whether to skip or recompress
   - Usually best to skip to avoid nested compression

8. **Destination filename collision**
   - Decide overwrite policy up front
   - Best default: fail that file rather than overwrite silently

9. **Source and destination are the same folder**
   - Ensure output path doesn’t conflict with source file handling
   - Direct-to-destination with `.gz` naming is usually safe

10. **Partial completion**
   - If some files succeed and some fail, `success=False`
   - Return the exact list of failures

## Goal
Take an input string, clean it, remove stopwords and duplicate tokens, then count n-grams (default: bigrams) and return the counts as a dictionary.

---

## Assumed behavior
Because the prompt says “Remove duplicate and stopwords from a string `text`” and then count n-grams, the most reasonable interpretation is:

1. Normalize the text.
2. Remove stopwords.
3. Remove duplicate tokens while preserving first occurrence order.
4. Build n-grams from the resulting token sequence.
5. Return a `dict` of n-gram counts.

---

## Implementation plan

### 1. Normalize input text
- Convert `text` to lowercase so counting is case-insensitive.
- Use regex to extract word tokens, ignoring punctuation and symbols.
  - Example: `re.findall(r"\b\w+\b", text.lower())`

This makes tokenization stable and avoids punctuation affecting n-grams.

---

### 2. Remove stopwords
- Use the provided `STOPWORDS` set.
- Filter out any token that appears in `STOPWORDS`.

Example:
- `"This is a simple test"` → `["simple", "test"]`

---

### 3. Remove duplicates while preserving order
- Build an ordered unique token list.
- Track seen tokens using a `set`.
- Keep only the first occurrence of each token.

Example:
- `["apple", "banana", "apple", "pear"]` → `["apple", "banana", "pear"]`

Preserving order matters because n-grams depend on sequence.

---

### 4. Validate `n`
- Ensure `n` is a positive integer.
- If `n <= 0`, return `{}` or handle gracefully.
- If the number of remaining tokens is less than `n`, return `{}`.

---

### 5. Generate n-grams
- Create consecutive token tuples of length `n`.
- For each window, join tokens with a space.

Examples:
- tokens `["data", "science", "model"]`, `n=2`
  - `("data science", "science model")`
- tokens `["a", "b", "c"]`, `n=3`
  - `("a b c")`

---

### 6. Count n-grams
- Use `collections.Counter` over the generated n-gram strings.
- Return `dict(counter)`.

---

### Input with repeated words only
- Example: `"hello hello hello"`
- After deduplication, only `["hello"]`
- For default `n=2`, return `{}`

### `n` larger than token count
- Example: `text="one two"`, `n=3`

### Non-string input
- If needed, convert to string or reject invalid input.
- Safer option: if `text` is not a string, cast with `str(text)` or return `{}` depending on desired strictness.

### Mixed case and punctuation
- `"Hello, HELLO!"` should normalize to the same token.
- Lowercasing and regex tokenization handle this.

### Stopwords with contractions / apostrophes
- Regex tokenization like `\b\w+\b` may split `"don't"` into `["don", "t"]`.
- If that matters, use a more permissive regex or accept that limitation.

3. **Generate random salt**
   - Use `os.urandom(SALT_LENGTH)` to create a cryptographically secure salt

4. **Derive hash**

     - password bytes
     - generated salt
     - iteration count: choose a reasonable secure default if not otherwise specified
   - The output should be raw bytes

5. **Base64-encode outputs**
   - Encode the salt with `base64.b64encode(salt)`
   - Encode the hash with `base64.b64encode(derived_hash)`
   - Both results remain `bytes`

6. **Return result**

## Goal
Compress every regular file in `src_folder` using the external `gzip` command, then move the resulting `.gz` files into `dst_folder`, and return a status dictionary:

```python
{
    "success": bool,
    "message": str,
    "failed_files": list[str]
}
```

---

## Proposed behavior

### 1. Validate inputs and environment
- Check that `src_folder` exists and is a directory.
- Ensure `dst_folder` exists; if not, create it.
- If `src_folder` is missing or not a directory, return failure immediately.
- If `dst_folder` cannot be created or written to, return failure.

### 2. Enumerate source files
- List files directly inside `src_folder`.
- Process only regular files.
- Skip directories and other non-file entries.
- Decide whether to skip existing `.gz` files:
  - Recommended: skip them to avoid recompressing already compressed files.
  - Alternative: include them only if explicitly required, but that is usually undesirable.

### 3. Compress files with `gzip` in the background
- For each eligible file:
  - Launch `gzip` using `subprocess.Popen(...)` rather than `subprocess.run(...)`, so the compression is started as a background process.
  - Use argument lists, not `shell=True`, to avoid quoting issues and improve safety.
  - Wait for each process to finish before moving the result.
- Since `gzip` normally deletes the original file and creates `filename.gz` in the same folder, use that output file for the move step.
- If `gzip` exits with a non-zero return code, record the file as failed.

### 4. Move compressed files to destination
- After successful compression, move `src_folder/<name>.gz` to `dst_folder/<name>.gz`.
- Use `shutil.move(...)`.
- If moving fails, record the file as failed.
- If the `.gz` file is missing after a successful `gzip` return code, treat it as a failure.

### 5. Build the return dictionary
- `success` should be `True` only if all eligible files were compressed and moved successfully.
- `failed_files` should contain the names of any files that failed at either compression or move stage.
- `message` should summarize:
  - how many files were processed,
  - how many succeeded,
  - how many failed,
  - and whether the operation completed fully or partially.

## Suggested algorithm
1. Initialize `failed_files = []`, `processed_count = 0`, `success_count = 0`.
2. Validate `src_folder` and `dst_folder`.
3. Create `dst_folder` if needed.
4. Collect source files with `glob(os.path.join(src_folder, "*"))`.
5. For each path:
   - Skip if not a regular file.
   - Skip if already ends with `.gz` if that policy is chosen.
   - Launch `gzip` compression with `Popen`.
   - Wait for completion.
   - If compression fails: add filename to `failed_files`, continue.
   - Compute expected `.gz` path.
   - Move `.gz` to destination.
   - If move fails: add filename to `failed_files`, continue.
   - Increment success count.
6. Return result dict.

## Edge cases to handle

### Empty source folder
- If there are no eligible files, return:
  - `success=True` or `success=False` depending on desired interpretation.
- Recommended: `success=True` with a message like “No files to compress,” because nothing failed.

### Source folder missing
- Return failure with a clear message.
- Do not attempt compression.

### Destination folder missing
- Create it automatically if possible.
- If creation fails, return failure.

### Files with spaces or special characters
- Use `Popen` with a list of arguments, not a shell command string.
- This avoids quoting issues.

### Hidden files and dotfiles
- They are still regular files and should be processed unless explicitly excluded.

### Non-regular entries
- Ignore directories, symlinks, sockets, etc. unless the spec says otherwise.

### Existing `.gz` files
- Best to skip them to avoid recompression.
- If included, gzip would typically create nested `.gz.gz`, which is likely unintended.

### Compression failure
- Could happen due to permissions, file locks, missing gzip executable, or disk issues.
- Record the affected filename and continue processing other files.

### Move failure
- Could happen if destination is unavailable, permissions are insufficient, or file is locked.
- Record the filename and continue.

### `gzip` not installed
- Detect `FileNotFoundError` from `Popen`.
- Return failure immediately with a message indicating that `gzip` is unavailable.

### Partial success
- If some files succeed and others fail:
  - `success=False`
  - `failed_files` contains only failed names
  - message should note partial completion

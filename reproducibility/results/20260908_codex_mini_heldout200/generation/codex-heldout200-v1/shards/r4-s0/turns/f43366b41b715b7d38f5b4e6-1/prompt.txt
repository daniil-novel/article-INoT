## Edge cases to handle

### 1) `seed=None`
- The report should still work, just with non-deterministic values.

- Return an empty DataFrame with the correct columns.

- Then each student would have no grades to average.
- `statistics.mean([])` raises an error, so this case must be handled explicitly.
- Reasonable options:
  - set `"Average Grade"` to `NaN`
  - or `0`
- Best practice: use `NaN` to indicate “undefined average”.

### 4) Duplicate names
- Duplicate student or subject names are not inherently invalid.
- The DataFrame can still be created, though duplicate subject names may produce repeated columns.

### 5) Non-list iterables
- If `students` or `subjects` are tuples/generators, convert them to lists first if needed.
- This ensures predictable iteration and column creation.

### 6) Student or subject values not strings
- Pandas can still store them, but the function should avoid forcing unnecessary assumptions unless required.
- If needed, convert column labels to strings only if the task expects that.

### 7) Reproducibility and global state
- Avoid using `random.seed(seed)` directly if possible, because it mutates global state.
- A local `random.Random(seed)` instance is safer.

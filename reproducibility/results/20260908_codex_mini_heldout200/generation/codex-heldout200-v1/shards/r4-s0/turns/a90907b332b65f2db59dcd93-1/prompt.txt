## Edge cases to handle

### 2. Empty arrays
If a series has no valid numeric values after cleaning:
- skip it or raise an error
- best practice: raise a clear exception unless silent skipping is desired

### 3. Too few points
A normal fit is not meaningful with:
- zero points
- one point

At least two valid values are needed to estimate variance reliably.

### 4. Zero variance
If all values are identical:
- standard deviation becomes 0
- `stats.norm.pdf` will fail with zero scale

Fix by:
- using a tiny epsilon, e.g. `1e-8`
- or plotting a narrow spike-like curve around the mean

### 5. NaN / inf values
Must be filtered out before computing statistics.

### 6. Non-numeric data
If an array contains strings or mixed types:

### 7. Very different scales across compounds

### 9. Duplicate labels

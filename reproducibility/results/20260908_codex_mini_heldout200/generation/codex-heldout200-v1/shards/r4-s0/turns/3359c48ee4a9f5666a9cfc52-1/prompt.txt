## Suggested uniformity check strategy

### For numeric columns
- Drop `NaN` values.
- If there are too few unique values or too few non-null values, skip formal testing and treat as non-uniform or “cannot assess” depending on desired behavior.
- Build histogram bins, ideally with a fixed number of bins such as 10.
- Compute observed counts in each bin.
- Compute expected counts assuming a uniform distribution across bins.
- If expected counts are valid, apply a chi-square goodness-of-fit test.
- If the p-value is below a threshold like `0.05`, print that the column is non-uniform.

### For non-numeric columns
- Since histograms and uniformity checks are less meaningful for arbitrary strings/categories, either:
  - Treat categories as discrete values and check uniformity over category frequencies, or
  - Skip formal uniformity testing and print a message that the column type is unsupported for uniformity assessment.
- If the task expects all columns to be processed, categorical frequency-based uniformity is a reasonable approach.

## Goal
- Generate `n` random Unix timestamps.
- Convert each timestamp to a UTC-formatted string using `DATE_FORMAT = "%Y-%m-%d %H:%M:%S"`.
- Plot a histogram of the generated timestamps.
- If `output_path` is provided, save the plot there; otherwise display it.
- Return a `list` of the formatted timestamp strings.

---

## Implementation plan

### 1. Validate inputs
- Ensure `n` is an integer.
- Ensure `n >= 0`.
- Optionally validate `output_path` is either `None` or a string-like path.

### 2. Choose a timestamp range
- Use a sensible Unix timestamp range to generate random values.
- Common choice:
  - `start_ts = 0` (1970-01-01 UTC)
  - `end_ts = current time in UTC` or a fixed upper bound
- This keeps generated timestamps valid and easy to interpret.

### 3. Generate `n` random Unix timestamps
- Use `random.randint(start_ts, end_ts)` for each timestamp.
- Store these in a list, e.g. `timestamps`.

### 4. Convert timestamps to UTC strings
- For each Unix timestamp:
  - Use `datetime.utcfromtimestamp(ts)` to interpret it as UTC.
  - Format with `.strftime(DATE_FORMAT)`.
- Collect results into a list and return it.

### 5. Create histogram
- Use `matplotlib.pyplot.hist(timestamps, bins=...)`.
- Since Unix timestamps are numeric, they can be directly plotted.
- Choose a reasonable number of bins, e.g.:
  - `min(10, max(1, n))` or a fixed moderate number
- Add labels:
  - title
  - x-axis label: “Unix timestamp”
  - y-axis label: “Frequency”

### 6. Save or display plot
- If `output_path` is provided:
  - Call `plt.savefig(output_path, bbox_inches="tight")`
- Otherwise:
  - Call `plt.show()`
- Always close the figure afterward with `plt.close()` to avoid side effects.

### 7. Return value
- Return the list of formatted timestamp strings.

## Edge cases to handle
1. **`n = 0`**
   - Return an empty list.
   - Still create a plot; it may be empty or skipped depending on design.
   - Prefer either:
     - show/save an empty histogram, or
     - handle gracefully with a message/title indicating no data.

2. **`n < 0`**
   - Raise `ValueError` because negative sample sizes are invalid.

3. **`n` is not an integer**
   - Raise `TypeError` or `ValueError`.

4. **Very large `n`**
   - Could create a heavy plot and large memory use.
   - The function should still work, but note performance may degrade.

5. **Invalid `output_path`**
   - If saving fails due to bad path/permissions, let the exception propagate or handle it explicitly.

6. **Timezone correctness**
   - Use UTC conversion explicitly, not local time conversion.

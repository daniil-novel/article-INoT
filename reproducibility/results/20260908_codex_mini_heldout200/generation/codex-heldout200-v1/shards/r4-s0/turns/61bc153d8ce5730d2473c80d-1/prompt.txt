## Requirements analysis

You need a function:

```python
import subprocess
import os
import sys
import glob
def task_func(directory_path):
```

that:

1. Looks in the given directory for all `.bat` files.
2. Runs each `.bat` file.
3. Returns a list of tuples:
   - first item: the file name
   - second item: its exit code
4. If a file cannot be executed, its exit code must be `None`.

## Implementation plan

### 1) Validate and normalize the input path
- Accept `directory_path` as a string.
- Check whether it points to an existing directory.
- If it does not, return an empty list.

### 2) Find `.bat` files
- Use `glob.glob(os.path.join(directory_path, "*.bat"))` to collect matching files.
- Prefer sorting the result so output order is deterministic.
- Use only files directly inside the directory unless recursion is explicitly required.

### 3) Execute each batch file
- For each `.bat` file:
  - Extract the file name with `os.path.basename(...)`.
  - Run it through Windows shell execution, typically via:
    - `subprocess.run(["cmd", "/c", bat_path], ...)`
- Capture the return code from the completed process.
- Append `(file_name, return_code)` to the output list.

### 4) Handle execution failures
- Wrap execution in `try/except`.
- If launching the file raises an exception, append:
  - `(file_name, None)`

### 5) Return final result
- Return the full list of tuples after processing all `.bat` files.

---

## Edge cases to consider

### Invalid directory
- If `directory_path` does not exist or is not a directory:
  - return `[]`

### No `.bat` files found
- Return `[]`

### File execution errors
Treat these as non-executable and return `None` for exit code:
- permission issues
- missing `cmd.exe`
- unsupported environment
- OS errors while starting the process
- unexpected subprocess exceptions

### Non-zero exit codes
- A batch file that runs but fails should still return its actual exit code, not `None`.

### Filenames with spaces or special characters
- Use path-safe subprocess invocation, not a shell-constructed command string.

### Duplicate filenames in different locations
- Since only one directory is searched non-recursively, duplicates are not expected.
- Return the basename of each file as requested.

### Case sensitivity
- `.bat` matching should work for normal Windows usage.
- If broader compatibility is needed, you could also consider `.BAT`, but on Windows globbing usually handles this adequately.

## Suggested behavior summary

- Input invalid or no files: `[]`
- File executed successfully: `("script.bat", 0)` or another integer exit code
- File failed to launch: `("script.bat", None)`

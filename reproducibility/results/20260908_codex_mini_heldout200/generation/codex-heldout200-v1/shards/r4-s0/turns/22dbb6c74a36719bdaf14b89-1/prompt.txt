- Input must be a string.
- If `s` is not a string, the function should raise an error.
- Letter counting is case-insensitive, so `A` and `a` count together.
- The chart should be titled **"Letter Frequencies"**.
- X-axis label: **"Letters"**
- Y-axis label: **"Frequency"**

- Ignore digits, punctuation, spaces, symbols, and other non-letter characters.

### Goal
- Generate all subsets of `elements` of size `subset_size`.
- For each subset, compute its sum.
- Return:

  2. the top `top_n` subset sums as a `pandas.Series`

### Implementation approach

1. **Handle trivial edge cases first**
   - If `subset_size == 0`, return `1` for the product and an empty or trivial `Series` result depending on the intended semantics.
   - If `subset_size > len(elements)`, return `1` for the product and an empty or trivial `Series`.
   - These cases should short-circuit before any subset generation.

2. **Generate subsets**
   - Use `itertools.combinations(elements, subset_size)` to enumerate all size-`subset_size` subsets.
   - This works naturally for tuples and preserves element order from the original tuple.

3. **Compute subset sums**
   - Convert each combination to `sum(combination)`.
   - Store all sums in a list for later processing.

4. **Compute product of sums**
   - Start from `1`.
   - Multiply all subset sums together.
   - Use `math.prod(...)` if available/appropriate, or a loop for clarity and compatibility.
   - If there are no valid subsets, return `1`.

5. **Compute top_n sums**
   - Sort the list of subset sums in descending order.
   - Take the first `top_n` values.
   - Wrap the result in `pandas.Series`.

6. **Return both outputs**
   - Return a 2-tuple: `(product_of_sums, top_sums_series)`.

- **`subset_size == 0`**

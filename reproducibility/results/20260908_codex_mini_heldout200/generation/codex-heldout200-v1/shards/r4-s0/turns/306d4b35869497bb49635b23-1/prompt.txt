## Goal
Build a function that:

1. Selects products listed in `product_keys` from `product_dict`
2. Creates a `pandas.DataFrame` with columns:
   - `Product`
   - `Quantity`
   - `Price`
   - `Profit`
   - `Average Price`
   - `Average Profit`
3. Computes average price and average profit across all included products
4. Plots a bar chart of `Profit` per product
5. Returns:
   - the DataFrame
   - the matplotlib `Axes` object, or `None` if there are no valid products

---

## Recommended implementation steps

### 1. Initialize containers
- Create empty lists for:
  - product names
  - quantities
  - prices
  - profits

These lists will hold the filtered products in the order of `product_keys`.

---

### 2. Iterate through `product_keys`
For each key in `product_keys`:

- Check whether the key exists in `product_dict`
- If it exists, extract:
  - `quantity`
  - `price`
  - `profit`
- Append values to the lists

### Important
Keep the order from `product_keys`, not from `product_dict`.

---

### 3. Handle missing or invalid products
If a key in `product_keys` is not present in `product_dict`:

- Best robust behavior: skip it
- Alternative behavior: raise an error, but skipping is safer for a report-style function

If no valid products remain after filtering:
- Return an empty DataFrame with the required columns
- Return `None` for the chart

---

### 4. Build the DataFrame
Create a DataFrame with columns:

- `Product`
- `Quantity`
- `Price`
- `Profit`

Then compute averages:

- `avg_price = np.mean(prices)` if list is not empty, otherwise `np.nan`
- `avg_profit = np.mean(profits)` if list is not empty, otherwise `np.nan`

Add these as new columns:
- `Average Price`
- `Average Profit`

Each row should contain the same average values, since they represent the overall averages for the selected products.

---

### 5. Plot the bar chart
If there is at least one valid product:

- Create a matplotlib figure and axes
- Plot a bar chart with:
  - x-axis: product names
  - y-axis: profit values
- Add:
  - title, e.g. `"Profit by Product"`
  - x-label: `"Product"`
  - y-label: `"Profit"`
- Optionally rotate x-tick labels if names are long

Return the `Axes` object.

If there are no valid products:
- Do not create a plot
- Return `None`

---

## Edge cases to handle

### 1. Empty `product_keys`
- Output should be an empty DataFrame with the required columns
- Plot should be `None`

### 2. `product_keys` contains unknown product names
- Skip missing keys gracefully
- If all keys are missing, treat it like an empty result

### 3. Empty `product_dict`
- Same behavior as empty result:
  - empty DataFrame
  - `None` for axes

### 4. Non-numeric values in `Quantity`, `Price`, or `Profit`
- Ideally convert to numeric where needed or rely on valid input
- If invalid values appear, `np.mean` may fail or produce bad results
- A robust version should validate or coerce numeric fields

### 5. Duplicate product names in `product_keys`
- Decide whether duplicates should appear multiple times
- Usually yes, because the input list defines the report rows
- If duplicates are not desired, de-duplicate explicitly, but that changes semantics

### 6. Missing fields inside a product entry
For example, if `product_dict[key]` lacks `profit`:
- Either skip that product
- Or raise a clear exception
- For a report generator, skipping invalid rows is often safer

### 7. No valid rows after filtering
- Return empty DataFrame with correct columns
- Return `None` for the plot

## Goal
For each inner list in `list_of_lists`, create a `Counter` representing a shopping cart:

- The cart contains randomly selected items.
- Each item is chosen from `POSSIBLE_ITEMS`.
- The number of picks equals the length of the inner list.
- Return a list of these `Counter` objects as `baskets`.

---

## Planned approach

1. **Initialize an output list**
   - Create an empty list `baskets = []`.

2. **Process each inner list**
   - Iterate over every `sublist` in `list_of_lists`.
   - Determine its size using `len(sublist)`.

3. **Generate random items for that basket**
   - For each position from `0` to `len(sublist) - 1`, pick one random item from `POSSIBLE_ITEMS` using `choice(POSSIBLE_ITEMS)`.

4. **Build a Counter**
   - Pass the randomly generated items into `Counter(...)`.
   - This counts repeated selections naturally.

5. **Append to output**
   - Add the resulting `Counter` to `baskets`.

6. **Return**
   - Return `baskets`.

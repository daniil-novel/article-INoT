## Edge cases to handle

- `config_file_path` does not exist → `FileNotFoundError`
- Config file is empty or malformed → `Exception`
- Missing `[Project]` section → `Exception`
- Missing `directory` field → `Exception`

### Project directory issues
- Directory path in config does not exist → `FileNotFoundError`
- Path points to a file instead of a directory → `FileNotFoundError` or `Exception` depending on implementation choice, but it should fail clearly

### Archive output issues
- `archieve_dir` does not exist
- `archieve_dir` cannot be created
- No write permission in `archieve_dir`
- Archive file already exists
  - Decide whether to overwrite or fail; `shutil.make_archive` may overwrite existing output depending on how it is used, so the implementation should be consistent and safe

### Path/name issues
- Project directory ends with a trailing slash
- Project basename is empty or invalid
- Directory name contains spaces or non-ASCII characters
- Windows vs Unix path separators

### Runtime/archive issues
- ZIP creation interrupted
- Source directory contains unreadable files
- Very large project directories
- Symlinks or special files inside the project directory

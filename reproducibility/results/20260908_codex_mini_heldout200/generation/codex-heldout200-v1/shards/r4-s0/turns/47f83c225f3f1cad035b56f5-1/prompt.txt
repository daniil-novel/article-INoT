### 3. Missing feature or target columns
- A requested feature or the target may not exist in the merged dataframe.
- Raise a clear error listing the missing columns.

### 4. Non-numeric data
- Linear regression requires numeric input.
- If feature/target columns contain strings or mixed types:
  - convert if possible, or
  - raise an error if conversion fails.

### 5. Missing values
- Rows with NaN in features or target will break fitting.
- Decide a consistent policy:
  - drop incomplete rows, or
  - raise an error

### 7. Single-row or insufficient data
- Regression needs enough data to estimate coefficients.
- If the merged cleaned dataset is too small, fitting may still work but results may be unstable.
- Consider checking for at least 2 rows, and ideally more than the number of features.

### 8. Constant features
- If a feature has zero variance, regression can still run but may yield unstable or redundant coefficients.
- Usually no exception is required, but it’s worth noting.

### 9. Intercept type
- `model.intercept_` may be a NumPy scalar.

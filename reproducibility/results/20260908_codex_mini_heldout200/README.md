# Reserved 200-task experiment and evaluator controls

The task IDs were fixed from the original randomized reserved split before controls or model generation. The unchanged five-condition design assigns 1,000 candidates and 1,800 CLI turns on GPT-5.4 mini, medium reasoning. The first generation attempt is running; one shard stopped after a 180-second timeout. No held-out model quality has been inspected at this documentation checkpoint. See `HELDOUT200_EXECUTION_AMENDMENT.md` for a separately frozen continuation of never-submitted assignments only.

Control attempt 2 used the original development image: 181 reference programs passed and all 200 incorrect programs failed. Before generation, environment attempt 3 added pinned library dependencies and offline NLTK corpora: 193 references passed and all 200 incorrect programs failed. Seven tasks remain unavailable for quality analysis and stay in every assignment denominator. One reference failure reports missing TensorFlow; six have no diagnostic message. TensorFlow was excluded because its required protobuf version conflicts with the evaluator environment.

All original task, reference, test and incorrect-program bytes remain fixed. `controls/attempt3/independent_pre_generation_audit.json` (or the adjacent audit file) records the independent checks. The environment files record the actual image and verified parent image IDs. The Dockerfile uses a local parent tag; the parent identity was independently checked, not implied by an immutable FROM declaration. Earlier controls and build diagnostics are retained. No model success rate is inferred from a passing reference control.

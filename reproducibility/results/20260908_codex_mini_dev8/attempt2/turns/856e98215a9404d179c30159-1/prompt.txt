## Goal
- Take a file name from the predefined source directory.
- Copy it into the backup directory.
- Run the copied file as a subprocess.
- Return:
  - the subprocess exit code on success
  - `-1` if the backup/copy step fails

---

## Planned behavior

### 1) Build source and destination paths
- Treat `filename` as a file name relative to `DIRECTORY`.
- Construct:
  - `source_path = os.path.join(DIRECTORY, filename)`
  - `backup_path = os.path.join(BACKUP_DIRECTORY, filename)`
- Use `os.path.basename(filename)` or similar validation if you want to prevent path traversal like `..\..\evil.exe`.

### 2) Validate the source file
- Check that:
  - the source path exists
  - it is a file, not a directory
- If not, treat as backup failure and return `-1`.

### 3) Ensure backup directory exists
- If `BACKUP_DIRECTORY` does not exist, create it with `os.makedirs(BACKUP_DIRECTORY, exist_ok=True)`.
- If directory creation fails, return `-1`.

### 4) Copy the file
- Use `shutil.copy2(source_path, backup_path)` to preserve metadata when possible.
- If copying fails for any reason, return `-1`.

### 5) Execute the copied file
- Run the copied file with `subprocess.run(...)`.
- Capture the exit code using `result.returncode`.
- Return that exit code.

---

## Edge cases to handle

### Invalid filename input
- `filename` is empty, `None`, or not a string.
- Recommended handling: return `-1`.

### Path traversal / unsafe path
- `filename` contains path separators or `..` segments.
- Recommended handling: normalize or reject anything outside `DIRECTORY`.

### Source file missing
- The specified file does not exist in `DIRECTORY`.
- Return `-1`.

### Source is a directory
- If `filename` points to a folder instead of a file.
- Return `-1`.

### Backup directory missing
- Create it automatically before copying.

### Copy permissions / access issues
- No read permission on source.
- No write permission in backup directory.
- Return `-1`.

### File already exists in backup
- Decide whether overwrite is allowed.
- `shutil.copy2` will overwrite by default if the destination exists.
- If overwriting is undesirable, explicitly check and handle it.

### Subprocess execution failure
- If the copied file cannot be launched, `subprocess.run` may raise `OSError` / `FileNotFoundError`.
- Even though the requirement only says `-1` for backup failure, a practical implementation should probably return `-1` here too, unless you want exceptions to propagate.

### Non-executable file types
- If the file is a script or non-binary file, direct execution may fail depending on file type and OS association.
- If needed, execution should be adapted by extension, e.g. using `sys.executable` for Python scripts.
- Since the task does not specify file type, the simplest approach is to execute the copied file directly and return the resulting exit code.

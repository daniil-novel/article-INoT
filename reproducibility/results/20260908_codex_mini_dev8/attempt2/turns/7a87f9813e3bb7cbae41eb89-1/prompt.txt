## Goal
Implement a function that:

1. Downloads a ZIP file from a URL
2. Extracts it into a target directory
3. Deletes the downloaded ZIP afterward
4. Returns the extraction directory path on success
5. Returns a descriptive error string on failure

---

## Planned behavior

### 1) Validate and prepare paths
- Accept:
  - `url: str`
  - `save_path: str = "downloaded_file.zip"`
  - `extract_path: str = "extracted_files"`
- Ensure the extraction directory exists before extraction:
  - create it if missing
- Make sure the ZIP save location is writable

---

### 2) Download the ZIP file
- Use `urllib.request` to download the file from `url` to `save_path`
- If the URL is invalid, the server is unreachable, DNS fails, or the request is blocked:
  - catch `urllib.error.URLError`
  - return a string in this format:
    - `URL Error: [error reason]`

---

### 3) Verify and extract the ZIP
- Open the downloaded file with `zipfile.ZipFile`
- Extract all contents into `extract_path`
- If the file is not a valid ZIP archive:
  - catch `zipfile.BadZipFile`
  - return a descriptive error message such as:
    - `ZIP Error: corrupted or invalid ZIP file`

---

### 4) Delete the ZIP file after extraction
- After successful extraction, remove `save_path` using `os.remove`
- If deletion fails due to permissions or filesystem issues:
  - catch `OSError`
  - return a descriptive file I/O error message

---

### 5) Return value
- On success:
  - return `extract_path`
- On failure:
  - return a clear string describing the problem

---

## Recommended exception handling strategy

Handle errors in this order:

1. `urllib.error.URLError`
   - Return: `URL Error: ...`
2. `zipfile.BadZipFile`
   - Return: ZIP corruption / invalid archive message
3. `OSError` / `IOError`
   - Covers filesystem issues:
     - permission denied
     - missing directories
     - extraction failures
     - deletion failures
     - disk errors
4. Optional broad `Exception`
   - As a final safeguard, return a generic unexpected error message

---

## Edge cases to account for

### URL / network issues
- Invalid URL format
- Unreachable server
- Timeout / DNS failure
- HTTP errors that surface through `URLError`

### ZIP issues
- File exists but is not a ZIP
- Corrupted archive
- Empty archive
- Archive with unusual or nested structure

### Filesystem issues
- `save_path` points to an unwritable location
- `extract_path` cannot be created
- Existing file blocks creation of `extract_path`
- Permission denied when deleting ZIP
- Disk full during download or extraction

### Cleanup issues
- Download succeeds but extraction fails:
  - ZIP file should ideally still be cleaned up if possible
- If deletion fails after successful extraction:
  - return a clear file I/O error

### Path safety
- ZIP entries may contain dangerous paths like `../`
- If robustness matters, validate extracted member paths to prevent path traversal
- This is a good hardening step even though it is not explicitly required

3. Open and extract ZIP
4. Delete downloaded ZIP
5. Return `extract_path`
6. On any failure, return a descriptive string

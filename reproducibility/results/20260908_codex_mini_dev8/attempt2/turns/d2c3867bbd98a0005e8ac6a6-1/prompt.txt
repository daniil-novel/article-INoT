## Recommended approach

### 1) Seed randomness for reproducibility
- Call `random.seed(seed)` at the start.
- This ensures empty lists get the same random values for the same seed.

### 2) Process each inner list independently
Because the input is a **list of lists**, and inner lists may be different lengths, the safest approach is:

- handle each inner list one by one
- convert the inner list to a NumPy array
- reshape it to a 2D array of shape `(-1, 1)` so `MinMaxScaler` can work
- scale it with `MinMaxScaler(feature_range=(0, 1))`
- convert the result back to a regular Python list

This avoids issues with ragged nested lists.

### 3) Handle empty inner lists
For any inner list that is empty:
- generate 5 random integers using `random.randint(0, 100)`
- use those as the data to scale

### 4) Collect results
- Append the scaled version of each processed inner list into the output list
- Return the final list of lists

### Negative values or values larger than 100

- `MinMaxScaler` will fail if any inner list contains strings, `None`, etc.

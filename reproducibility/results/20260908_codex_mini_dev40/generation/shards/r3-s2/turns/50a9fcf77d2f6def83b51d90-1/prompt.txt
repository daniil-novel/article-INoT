## Important edge cases

### Empty series
- If one or both series are empty after removing missing values:
  - intersection count should be `0`
  - plot should still be created without error

### No overlap
- If there are no shared values:
  - draw no red lines
  - return `intersection_count = 0`

### Duplicate values
- If a value appears multiple times in either series:
  - it should still count only once toward `intersection_count`
  - the swarm plot will naturally show repeated observations as multiple points

### Missing values
- `NaN` should be ignored in both overlap detection and plotting
- Do not count `NaN` as an intersection

### Non-numeric data
- Since swarm plots require meaningful numeric y-values, the function should assume numeric or at least numeric-compatible input.
- If inputs may contain non-numeric data, either:
  - coerce safely to numeric, or
  - rely on pandas/seaborn to raise a clear error
- Best practice: document that the function is intended for numeric series.

### Identical series
- If both series contain the same unique values:
  - `intersection_count` should equal the number of unique values shared
  - all those values should get red dashed lines

### Very dense data / many duplicates
- Swarm plots can become crowded.
- The plot should still work, but you may want to keep marker size modest for readability.

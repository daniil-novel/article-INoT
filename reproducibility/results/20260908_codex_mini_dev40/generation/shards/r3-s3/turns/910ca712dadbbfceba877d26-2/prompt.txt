## Goal

2. **Normalize the hex string**
   - Strip surrounding whitespace.
   - Optionally handle a `0x` / `0X` prefix if present.
   - Keep the original case irrelevant since hex parsing is case-insensitive.

3. **Validate the input**
   - Ensure the remaining string contains only valid hex characters.
   - Prefer enforcing length `8` hex digits for a binary32 value.
   - If the input is malformed, raise a `ValueError` with a clear message.

4. **Convert hex to raw bytes**
   - Parse the hex string into a 4-byte sequence.
   - Use big-endian interpretation unless the problem explicitly states otherwise.
   - This is important because IEEE-754 float bytes are order-sensitive.

5. **Unpack bytes into a Python float**
   - Use `struct.unpack('>f', ...)` to interpret the 4 bytes as a binary32 float.

     - `+0.0` / `-0.0`
     - `inf` / `-inf`
     - `nan`

6. **Repack the float as binary32 bytes**
   - Use `struct.pack('>f', value)` to ensure the float is represented as a 4-byte binary32 value.
   - This step normalizes the float back into the exact binary32 layout before compression.

7. **Compress the binary32 bytes**
   - Pass the 4-byte result into `zlib.compress(...)`.
   - The output should be the compressed `bytes` object.

8. **Return result**

3. **Prefix handling**
   - Inputs like `0x470FC614` should either be supported by stripping the prefix or rejected consistently.
   - Supporting it makes the function more robust.

4. **Leading zeros**
   - Example: `00000001`
   - Must be preserved in parsing; do not trim them before conversion.

5. **Special floating-point values**
   - IEEE-754 bit patterns can represent:

   - The code should not try to “fix” them; just convert and repack.

   - Using native endianness can produce inconsistent results across platforms.

7. **Compression of very small payload**
   - A 4-byte input may compress to a larger output because of zlib headers.

import struct
import zlib

# Constants
KEY = '470FC614'


def task_func(hex_string=KEY):
    if not isinstance(hex_string, str):
        raise TypeError("hex_string must be a string")

    s = hex_string.strip()
    if s.startswith(("0x", "0X")):
        s = s[2:]

    if len(s) != 8:
        raise ValueError("hex_string must contain exactly 8 hex digits")

    try:
        raw_bytes = bytes.fromhex(s)
    except ValueError as exc:
        raise ValueError("hex_string must be a valid hexadecimal string") from exc

    # Convert the IEEE-754 binary32 bytes to a Python float
    value = struct.unpack(">f", raw_bytes)[0]

    # Repack as binary32 and compress
    binary32_bytes = struct.pack(">f", value)
    compressed_bytes = zlib.compress(binary32_bytes)

    return {"bytes": compressed_bytes}

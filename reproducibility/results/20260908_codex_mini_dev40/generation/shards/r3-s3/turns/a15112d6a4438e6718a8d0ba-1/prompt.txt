## Goal
Create `task_func(list_of_lists, seed=42)` that:
1. Accepts a list of lists of numbers.
2. Replaces any empty inner list with 5 random integers from 0 to 100.
3. Scales each inner list to the `[0, 1]` range using `MinMaxScaler`.
4. Returns a list of lists of floats.

---

## Proposed approach

### 1) Set deterministic randomness
- Call `random.seed(seed)` at the start so that empty-list replacement is reproducible.

### 2) Process each inner list independently
Because inner lists may have different lengths, the safest approach is to scale **each inner list separately**.
- For each sublist:
  - If it is empty, generate 5 random integers in `[0, 100]`.
  - Convert the values into a NumPy array of shape `(n, 1)` so `MinMaxScaler` can process it.
  - Apply `MinMaxScaler(feature_range=(0, 1))`.
  - Flatten the result back into a plain Python list of floats.

This preserves the structure of the input: each inner list remains one inner list in the output.

---

## Why per-list scaling is the right choice
- `MinMaxScaler` expects a 2D array.
- Inner lists may have different lengths, so stacking them together into one matrix may fail or require padding, which is not requested.
- The prompt says “values in a list of lists,” which strongly suggests scaling each list independently.

---

## Edge cases to handle

### 1) Empty inner lists
- Replace with exactly 5 random integers between 0 and 100 inclusive.
- Then scale those generated values.

### 2) Single-value lists
- `MinMaxScaler` on a single value produces `0.0` because min and max are the same.
- This should be accepted and returned as `[0.0]`.

### 3) Lists with identical values
- Example: `[7, 7, 7]`
- Min-max scaling would have zero range; `MinMaxScaler` returns all zeros.
- This is expected behavior.

### 4) Non-numeric values
- The prompt does not specify handling invalid types.
- In a robust implementation, you may let NumPy / sklearn raise an error naturally if non-numeric data is passed.
- If desired, explicit validation could be added, but it is not required by the task.

### 5) Outer empty list
- If `list_of_lists` is empty, return an empty list.

### 6) Lists containing floats or negative numbers
- These are valid inputs and should scale normally.

---

## Output requirements
- Return a `list` of `list`s of `float`s.
- Every value should be in `[0.0, 1.0]` after scaling, except for tiny floating-point precision artifacts that are normally negligible.

---

## Suggested implementation steps
1. Initialize `random.seed(seed)`.
2. Create an empty result list.
3. Loop through each inner list:
   - If empty, generate 5 random integers.
   - Fit a `MinMaxScaler` on the inner list reshaped to 2D.
   - Transform the values.
   - Convert back to a Python list and append to the result.
4. Return the result.

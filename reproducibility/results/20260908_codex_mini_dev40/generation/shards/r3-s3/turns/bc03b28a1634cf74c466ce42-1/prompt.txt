## Goal
Process all `.json` files in a directory in alphabetical order, load their contents into one `pandas.DataFrame`, add a `Source` column with the filename for each record, and move processed files into a `processed/` subdirectory. The input directory may not exist initially.

---

## Implementation plan

### 1) Ensure the input directory exists
- If `path` does not exist, create it.
- Also create a `processed` subdirectory inside it:
  - `path/processed`

This prevents failures when the directory is missing initially.

---

### 2) Find JSON files
- List all files in `path`
- Exclude the `processed` subdirectory
- Keep only files ending in `.json`
- Sort filenames alphabetically before processing

This guarantees deterministic processing order.

---

### 3) Process each JSON file
For each JSON file:
- Open and parse it using `json.load`
- Convert the parsed data to a DataFrame
- Add a `Source` column containing the filename

Recommended handling of JSON shapes:
- If the JSON root is a list of records, build `DataFrame(data)`
- If the JSON root is a dict, wrap it as one row: `DataFrame([data])`
- If the JSON root is something else, decide whether to:
  - convert it to a single-row representation, or
  - skip it as malformed for tabular use

---

### 4) Collect all rows
- Append each file’s DataFrame to a list
- After all files are processed, concatenate them with `pd.concat(..., ignore_index=True)`
- If no valid JSON files were found, return an empty DataFrame

---

### 5) Move processed files
- After a file is successfully read and converted, move it into `path/processed`
- Use `shutil.move`

Important:
- Move the file only after successful parsing, so invalid JSON is not accidentally marked as processed.

---

### 6) Return value
- Return the combined DataFrame as `df`

---

## Edge cases to handle

### Missing directory
- `path` may not exist initially
- Create it before listing files

### No JSON files
- Return an empty DataFrame

### Empty JSON files
- `json.load` will fail
- Either skip the file or raise a clear exception, depending on desired strictness

### Invalid JSON content
- Catch parsing errors
- Skip the file or stop execution with a meaningful error

### Mixed JSON structure
- Some files may contain lists, others dicts
- Normalize them into a consistent tabular form

### Non-JSON files in the directory
- Ignore them

### Existing `processed` folder
- Reuse it safely if already present

### Name collisions in `processed`
- If a file with the same name already exists there, decide whether to overwrite, rename, or raise an error
- The simplest behavior is to rely on `shutil.move` and let it handle platform-specific behavior

### Missing or inconsistent keys across files
- Pandas will create unioned columns and fill missing values with `NaN`
- This is expected and acceptable for combining heterogeneous JSON files

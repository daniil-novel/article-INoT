## Edge cases to consider

### 1. Empty array
- Not expected here because `ARRAY_SIZE = 10000`.
- If generalized later, mean/std on empty arrays would produce warnings or `nan`.

### 2. Standard deviation interpretation
- If someone expects sample standard deviation instead of population standard deviation, results would differ slightly.
- Since the task does not specify `ddof=1`, default `ddof=0` is safest.

### 3. Histogram binning
- If bins are not aligned to integers, the histogram may look less precise.
- Using integer-aligned bins avoids ambiguity.

### 4. Mean/std lines outside the range
- For data in `[1, 100]`, mean and `mean ± std` should normally fall within or near the range.
- If they fall outside due to unusual data, `axvline` still works.

### 5. Duplicate legend labels
- Drawing both `mean - std` and `mean + std` as purple lines can create duplicate legend entries.
- Better to label only the first or use a shared label once.

### 6. Plot object return type
- The task explicitly asks for the histogram plot as `Axes`, not `Figure`.
- Return the axes object (`ax`), not `plt` or `fig`.

Implementation plan:

1. **Read input**
   - Accept `content` as a sentence-like string.

2. **Tokenize the sentence**
   - Use `nltk.word_tokenize(content)` to split the sentence into word tokens.
   - This is preferable to simple `split()` because it handles punctuation more reliably.

3. **Remove the last word/token**
   - Exclude the final token from POS tagging:
     - If there is only 0 or 1 token, the result should be an empty dictionary.
   - Work with the remaining tokens only.

4. **POS tag the remaining tokens**
   - Apply `nltk.pos_tag()` to the truncated token list.

5. **Count POS tags**
   - Extract the tag from each `(word, tag)` pair.
   - Use `Counter` to count how many times each tag appears.

6. **Return result**
   - Convert the `Counter` to a regular `dict` and return it.

- **Trailing punctuation**: tokenization may separate punctuation into its own token; “last word” should be interpreted as the last token after tokenization unless the task specifies otherwise.
- **Multiple spaces / irregular whitespace**: tokenization should still work.
- **Non-standard text**: numbers, symbols, or mixed-language content may produce tags, but should still be counted normally if tokenized.

## Goal
Count the Part-of-Speech (POS) tags in a sentence **excluding the last word** and return the result as a dictionary:
- **keys**: POS tags
- **values**: counts of those tags

The code must be self-contained and begin with the provided NLTK setup.

---

## Implementation plan

### 1) Accept input
- The function takes `content`, which should be treated as a sentence/string.
- Convert to string if needed, or assume the input is already a string.

### 2) Tokenize the sentence
- Use `nltk.word_tokenize(content)` to split the sentence into words/tokens.
- This is necessary before POS tagging.

### 3) Remove the last word
- Exclude the final token from POS counting.
- If the token list has fewer than 2 tokens, there are no words left to tag after removing the last one.

### 4) POS tag the remaining tokens
- Apply `nltk.pos_tag(...)` to the tokens except the last one.
- This returns pairs like `(word, tag)`.

### 5) Count tag frequencies
- Extract only the tag part from each tagged pair.
- Use `collections.Counter` to count occurrences of each tag.

### 6) Return the result
- Convert the `Counter` to a regular dictionary and return it.
- Output should look like:
  ```python
  {'NN': 2, 'VB': 1, 'DT': 1}
  ```

---

## Edge cases to handle

### 1) Empty input
- If `content` is empty or tokenization yields no tokens:
  - Return `{}`

### 2) Single-word input
- After excluding the last word, nothing remains.
- Return `{}`

### 3) Punctuation-only or whitespace-only input
- Tokenization may produce no usable words.
- Return `{}`

### 4) Last token is punctuation
- The prompt says “last word,” but tokenization may treat punctuation as separate tokens.
- Decide consistently to exclude the **last token** after tokenization.
- This is the safest interpretation for deterministic behavior.

### 5) Mixed punctuation and contractions
- NLTK tokenization may split contractions like `"don't"` into multiple tokens depending on tokenizer behavior.
- POS tagging should still be applied to whatever tokens remain after removing the last token.

### 6) Non-string input
- If needed, convert with `str(content)` to avoid runtime errors.
- If strict behavior is preferred, the function can assume string input only.

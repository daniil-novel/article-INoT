## Goal
Count POS tags in a sentence **excluding the last word** and return a dictionary of tag counts.

## Planned approach
1. **Tokenize the input sentence**
   - Use NLTK tokenization to split `content` into words/tokens.
   - This is better than `str.split()` because it handles punctuation more reliably.

2. **Remove the last word/token**
   - Drop the final token from the token list.
   - If the sentence has only one token, the result should be an empty list.

3. **Handle empty input after trimming**
   - If no tokens remain after removing the last word, return `{}` immediately.

4. **POS tag the remaining tokens**
   - Use `nltk.pos_tag()` on the shortened token list.

5. **Count tag frequencies**
   - Extract the POS tags from the tagged output.
   - Use `Counter` to count occurrences of each tag.

6. **Return a dictionary**
   - Convert the `Counter` object to a plain `dict` before returning.

---

## Edge cases to consider
- **Empty string input**: should return `{}`.
- **Single-word sentence**: removing the last word leaves nothing, so return `{}`.
- **Punctuation at the end**:
  - If tokenization separates punctuation, dropping the last token may remove punctuation instead of the intended word depending on tokenization.
  - Using NLTK tokenization helps, but behavior should be consistent with “last word/token” interpretation.
- **Multiple spaces / irregular spacing**:
  - Tokenization should normalize this automatically.
- **Non-alphabetic tokens**:
  - Numbers, symbols, and punctuation may receive POS tags too; they should be counted like any other tag unless explicitly excluded.
- **Unexpected non-string input**:
  - If needed, either convert to string or fail naturally; the task doesn’t specify special handling.

## Stage 1 — Requirements analysis and implementation plan

### Goal
Implement `task_func(url, save_path="downloaded_file.zip", extract_path="extracted_files") -> str` that:

1. Downloads a ZIP file from `url`
2. Saves it to `save_path`
3. Extracts its contents into `extract_path`
4. Deletes the ZIP file afterward
5. Returns the extraction directory path on success
6. Returns a descriptive error string on failure

---

## Functional requirements

### Inputs
- `url: str` — source URL of the ZIP file
- `save_path: str` — local filename/path to store downloaded ZIP
- `extract_path: str` — directory where contents will be extracted

### Output
- On success: `str` path to `extract_path`
- On failure: `str` error message

### Error handling requirements
The function should handle and report:

- `urllib.error.URLError`
  - For invalid URL or unreachable server
  - Return format: `"URL Error: [error reason]"`
- Corrupted or invalid ZIP file
  - Return a descriptive ZIP-related error message
- File I/O errors
  - Return a descriptive file error message
- Any other unexpected failure
  - Return a generic descriptive error string

---

## Implementation plan

### 1. Validate/prepare paths
- Ensure `extract_path` exists before extracting:
  - `os.makedirs(extract_path, exist_ok=True)`
- Optionally ensure the parent directory for `save_path` exists if `save_path` includes folders.
  - Use `os.path.dirname(save_path)` and create it if needed.

### 2. Download the ZIP file
- Open the URL with `urllib.request.urlopen(url)`
- Read the response bytes
- Write bytes to `save_path` in binary mode

### 3. Extract the ZIP file
- Open downloaded file with `zipfile.ZipFile(save_path, "r")`
- Use `extractall(extract_path)`

### 4. Cleanup
- Delete the downloaded ZIP file after extraction
- This should happen even if extraction fails, if possible
- Use a `finally` block or equivalent cleanup logic

### 5. Return success value
- If everything succeeds, return `extract_path`

---

## Error handling strategy

### `urllib.error.URLError`
- Catch separately
- Extract a human-readable reason if possible:
  - `e.reason` if present
  - otherwise `str(e)`
- Return:
  - `f"URL Error: {reason}"`

### `zipfile.BadZipFile`
- Indicates corrupted or non-ZIP content
- Return something like:
  - `"ZIP Error: Invalid or corrupted ZIP file"`

### `OSError` / `IOError`
- Covers download write failures, directory creation failures, deletion failures, etc.
- Return descriptive message, e.g.:
  - `"File Error: {error message}"`

### Generic exception fallback
- Catch unexpected exceptions
- Return:
  - `"Error: {error message}"`

---

## Edge cases to account for

1. **Invalid URL**
   - Example: malformed URL string
   - Expected: `URLError` handling

2. **Server unreachable / DNS failure / timeout**
   - Expected: `URLError` handling

3. **URL returns non-ZIP content**
   - ZIP extraction should fail with `BadZipFile`

4. **ZIP file is corrupted**
   - Partial download or broken archive
   - `BadZipFile` should be caught

5. **Download succeeds but disk write fails**
   - Permissions issue, read-only path, invalid path
   - Handle as file I/O error

6. **Extraction directory cannot be created**
   - Permissions issue or invalid path
   - Handle as file I/O error

7. **ZIP contains nested directories**
   - `extractall` should handle this naturally

8. **Downloaded file should be deleted after use**
   - Ensure cleanup happens even if extraction fails

9. **Cleanup failure**
   - If ZIP deletion fails, decide whether to:
     - report as file error, or
     - ignore cleanup failure if extraction already succeeded
   - Best practice: attempt cleanup, but avoid hiding the primary error if one already occurred

10. **Empty archive**
   - Valid ZIP with no files should still extract successfully and return the directory path

---

## Suggested control flow

1. Create extraction directory
2. Download ZIP to `save_path`
3. Open and extract ZIP to `extract_path`
4. Delete ZIP file
5. Return `extract_path`

With exception handling around:
- URL download
- file writing
- ZIP extraction
- cleanup

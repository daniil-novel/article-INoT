## Edge cases to handle

### 1) Missing Excel file
- Must raise `FileNotFoundError`.

### 2) Missing sheet name
- Must raise `ValueError`.

### 3) Non-numeric values in the sheet
- Although the note says the Excel file should contain only numerical data, real inputs may still contain text, blanks, or mixed cells.
- Recommended behavior: raise `ValueError` if any non-numeric data is detected.

### 4) Empty sheet
- If the sheet exists but has no data:
  - return an empty dictionary `{}` or raise `ValueError`, depending on the intended strictness.
- Since the task does not specify this case, the safest implementation is to return `{}` only if the dataframe is empty and no columns exist.

### 5) Missing values (`NaN`)
- If numeric columns contain blanks, pandas sum will typically ignore them.
- This is usually acceptable, but you should be aware of it.
- If strict completeness is desired, you can treat missing values as invalid and raise `ValueError`.

### 6) Duplicate column names
- A dictionary cannot safely represent duplicate keys.
- If duplicate columns are possible, sums may overwrite each other in the returned dict.
- Recommended: either reject duplicate column names or document that the last duplicate wins.

### 7) CSV overwrite
- If `csv_file_location` already exists, it will be overwritten.
- This is acceptable unless the task needs preservation of the old file.

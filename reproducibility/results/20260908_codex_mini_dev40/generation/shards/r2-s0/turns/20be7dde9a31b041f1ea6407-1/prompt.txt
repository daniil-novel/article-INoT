## Goal
Scan all text files in a directory, extract matches using the provided regex, and return a dictionary:

- **keys**: file names only, no path
- **values**: lists of matches found in each file

- Convert `directory_path` to a `Path` object.
- Verify that it exists and is a directory.
- If it is invalid, decide on a consistent behavior:
  - either return `{}` for non-existent / invalid directory
  - or raise a clear exception like `NotADirectoryError`
- The safer implementation is usually to raise for invalid paths, but the final behavior should be consistent with project conventions.

### 2) Find text files in the directory
- Use `glob` or `Path.glob` to enumerate files in the specified directory.
- Restrict to regular files only.
- Treat “text files” as files with a `.txt` extension unless the task context says otherwise.
- Ignore subdirectories and non-file entries.

Possible file selection rule:
- `*.txt` for standard text files
- if broader support is desired, also allow files with no extension if they are plain text, but that requires content sniffing and is unnecessary here

### 3) Read each file safely
- Open each file with UTF-8 encoding.

### 4) Apply the regex
- Compile `regex_pattern` with `re.findall(...)` or `re.finditer(...)`.

## Suggested internal structure
1. Validate path
2. Iterate over text files
3. Read content

5. Normalize matches if `findall` returns tuples because of capture groups

7. Return result

## One subtle point to watch
If the regex contains capturing groups, `re.findall()` may return:
- a list of strings, or
- a list of tuples

So the implementation should either:
- use non-capturing groups in the regex, or
- normalize tuple results before storing them

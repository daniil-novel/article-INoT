## Edge cases to handle

### `n_components == 1`
- Do not attempt to draw a covariance heatmap.
- Return `None` for `heatmap_axes`.

### `n_components > min(N_SAMPLES, N_FEATURES)`
- Raise `ValueError`.

### `N_SAMPLES == 1`
- PCA is not meaningful with a single sample.
- Should raise `ValueError`.

### `N_FEATURES == 1`
- PCA can only produce 1 component.
- If `n_components > 1`, raise `ValueError`.

### `random_seed is None`
- Use nondeterministic randomness or default RNG behavior.
- Function should still work.

### Constant / near-constant data
- Unlikely with random generation, but if the generation method produces degenerate variance, PCA may warn or return poor results.
- Using random Gaussian data avoids this.

## Requirements understanding

2. For each trial, compute the sum of the dice.
3. Count how many times each sum occurs using `Counter`.
4. Build a bar plot showing the distribution of sums:
   - x-axis: sum of dice rolls
   - y-axis: count
   - title should describe the distribution of dice roll sums
5. Return a tuple:

## Planned implementation steps

### 1. Seed the random generator
- Call `random.seed(random_seed)` at the start so results are reproducible.

### 2. Simulate dice rolls
- Repeat `num_rolls` times:
  - Generate `num_dice` random integers in `[1, 6]`
  - Sum them
  - Store the sum in a list or update a `Counter` directly

### 3. Count frequencies
- Use `Counter` to count all observed sums.
- This will form the distribution returned by the function.

### 4. Prepare plot data
- The possible sums range from:
  - minimum: `num_dice` if all dice show 1
  - maximum: `6 * num_dice` if all dice show 6
- For a clean bar plot, include every possible sum in this interval, even if count is zero.
- This ensures the x-axis is continuous and visually correct.

### 5. Create the bar plot
- Use `plt.subplots()` to obtain `fig, ax`
- Plot bars for each possible sum
- Set:
  - title: something like `"Distribution of Dice Roll Sums"`
  - x-label: `"Sum of Dice Roll"`
  - y-label: `"Count"`

### 6. Save plot if requested
- If `plot_path` is not `None`, call `fig.savefig(plot_path)`.

### 7. Return output

## Edge cases to handle

### 1. `num_rolls = 0`
- No simulations are performed.
- Expected output:
  - empty `Counter`
  - plot may be empty or show zero counts if full range is still drawn
- Best approach: create an empty or zero-valued plot gracefully without failing.

### 2. `num_dice = 1`
- Sums are just the die values 1–6.
- This should work naturally.

### 3. `num_dice <= 0`
- A standard die simulation with zero or negative dice is invalid.
- Recommended behavior: raise `ValueError`.

### 4. `num_rolls < 0`
- Negative number of trials is invalid.
- Recommended behavior: raise `ValueError`.

### 5. Non-integer inputs
- If `num_rolls` or `num_dice` are not integers, results are undefined.
- Recommended behavior: either validate and raise `TypeError`/`ValueError`, or rely on Python iteration errors.
- Best practice: explicit validation for clearer failures.

### 6. Very large values
- Large `num_rolls` and `num_dice` may be slow.
- Complexity is `O(num_rolls * num_dice)`.
- Memory use can be kept modest if counts are accumulated directly rather than storing all sums.

### 7. `plot_path` is provided but unwritable
- Saving could fail due to filesystem/path issues.
- If not required to catch errors, let the save operation raise naturally.

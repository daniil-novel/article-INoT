## Serialization policy choice
For `Decimal`, there are two common approaches:
- **Convert to `float`**: preserves numeric JSON type, but may lose precision
- **Convert to `str`**: preserves exact value, but changes JSON type to string

Because the task says “properly serialized” and emphasizes complex data types not natively supported, a safe and precise choice is usually:
- `Decimal` → `str`
- `datetime` → ISO string

This avoids precision loss and is deterministic.

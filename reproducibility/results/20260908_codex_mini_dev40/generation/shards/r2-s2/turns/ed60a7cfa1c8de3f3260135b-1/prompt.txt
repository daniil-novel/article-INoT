## Goal
Process every `.xlsx` file in the target directory and escape all double quotes in all cell values by prefixing each `"` with `\\`.

The function should return:

- `int`: the number of Excel files processed

---

## Implementation plan

### 1) Discover Excel files
- Use `glob.glob(os.path.join(directory_path, '*.xlsx'))` to collect all `.xlsx` files in the specified directory.
- Process only files directly under that directory unless the requirement later expands to subdirectories.

### 2) Open each workbook safely
- For each file path:
  - Load the workbook with `openpyxl.load_workbook`.
  - Use the normal editable mode so changes can be saved back.
- If a workbook cannot be opened or is corrupted, decide whether to:
  - skip it and continue, or
  - let the exception propagate
- Since the task asks for processing all files, the more robust behavior is to skip unreadable files and continue.

### 3) Traverse all sheets and all cells
- For every worksheet in the workbook:
  - Iterate through all populated cells using `sheet.iter_rows()`.
- For each cell:
  - Check whether the value is a string.
  - If it contains `"` characters, replace every `"` with `\\\"` logically as text content, meaning:
    - each double quote becomes two backslashes followed by a quote in the resulting string representation
    - in Python string literal terms, the replacement string should be carefully represented so the cell ends up containing the intended text

### 4) Preserve non-string values
- Do not modify:
  - integers
  - floats
  - booleans
  - dates
  - formulas if they are not stored as plain strings
  - `None`
- Only string cell contents should be changed.

### 5) Save the workbook
- After modifying all relevant cells in a workbook, save it back to the same file path.
- This updates the file in place.

### 6) Count processed files
- Increment a counter for each `.xlsx` file successfully processed.
- Return that counter at the end.

---

## Edge cases to handle

### Empty directory
- If no `.xlsx` files exist, return `0`.

### Cells with no value
- Skip `None` values.

### Cells containing only quotes
- Example: `"""` should be transformed correctly by replacing every quote individually.

### Strings already containing backslashes
- Backslashes should remain unchanged; only `"` characters are modified.

### Mixed-content strings
- Example: `He said "hello"` should become `He said \\\"hello\\\"` in stored text form.

### Hidden sheets / multiple sheets
- All worksheets should be processed, including hidden ones, unless explicitly excluded.

### Formula cells
- Do not alter formulas unless they are plain string values that literally contain quotes as text.

### Non-UTF-8 or unusual text
- `openpyxl` handles standard workbook text; no extra encoding logic should be needed.

### Read-only or locked files
- If saving fails because the file is locked or unreadable, skip or report according to desired robustness; for a resilient utility, continue processing remaining files.

### Invalid `.xlsx` files
- A file with `.xlsx` extension but not a valid workbook should be skipped or handled gracefully.

## Behavioral notes
- The operation is destructive/in-place: it rewrites the original workbook files.
- The function should be idempotent in the sense that:
  - after one pass, quotes are escaped
  - running it again would escape the newly inserted quote characters again unless the caller prevents reruns
- If strict single-escape behavior is desired, the code would need a guard to avoid double-escaping already escaped quotes. The current requirement does not explicitly ask for that, so the straightforward replacement is acceptable.

Here’s an implementation plan for `task_func(directory_path='./xlsx_files/')` that meets the requirement of protecting all double quotes in all `.xlsx` files in the specified directory by prefixing them with a double backslash.

## Goal
Process every Excel workbook in `directory_path` and replace every literal double quote (`"`) in cell text with `\\"` so the quotes are protected. Return the number of Excel files processed.

## Proposed approach

1. **Collect target files**
   - Use `glob.glob(os.path.join(directory_path, '*.xlsx'))` to find all `.xlsx` files in the directory.
   - Ignore temporary Excel lock files such as `~$*.xlsx` if they appear.

2. **Open each workbook**
   - Load each file with `openpyxl.load_workbook(...)`.
   - Use `keep_vba=False` unless macro support is needed; the task only mentions `.xlsx`, so standard workbook handling is enough.
   - Process all sheets in the workbook.

3. **Traverse all cells**
   - For each worksheet, iterate through all populated cells using `worksheet.iter_rows()`.
   - Check only string-like cell values.
   - If a cell value is a string and contains `"`, replace every `"` with `\\"`.

4. **Write changes back**
   - Save the modified workbook back to the same file path.
   - If no cells were changed, the workbook can still be saved or skipped; either is acceptable unless you want to avoid unnecessary rewrites.

5. **Return result**
   - Return the count of `.xlsx` files successfully processed.

## Important implementation details

### Quote replacement rule
- Each double quote must be prefixed with a **double backslash**.
- In Python string literal form, the replacement string should be written carefully to produce the actual text `\\"`.
- The intended stored cell text should become:
  - `He said "hi"` → `He said \\"hi\\"`

### Type handling
Only modify:
- `str` values

Do not modify:
- `None`
- numbers
- booleans
- dates/datetimes
- formulas
- error values

### Workbook structure
Ensure processing covers:
- All worksheets in the workbook
- All populated cells, including cells in merged regions if they store values in the top-left cell
- Cells inside tables/charts are not required unless they are regular cell values

## Suggested edge cases

1. **Empty directory**
   - No `.xlsx` files found.
   - Return `0`.

2. **Files with no quote characters**
   - File is still a valid target.
   - Either save unchanged or skip save; return count as processed if opened successfully.

3. **Multiple quotes in one cell**
   - Replace all occurrences, not just the first.

4. **Cells containing formulas**
   - Do not alter formula strings unless the task explicitly says formulas should be edited.
   - In `openpyxl`, formulas are also stored as strings starting with `=`, so decide whether to preserve them untouched.

5. **Cells with embedded special text**
   - Strings containing newline characters, tabs, or Unicode should remain intact except for quote replacement.

6. **Hidden sheets**
   - Hidden worksheets should still be processed, since they are part of the workbook.

7. **Read-only / locked files**
   - If a workbook cannot be opened or saved, skip it and continue, unless you want the function to fail fast.
   - Since the requirement asks for the number processed, it’s usually better to count only successfully processed files.

8. **Temporary Excel lock files**
   - Skip files beginning with `~$` to avoid processing temp lock files.

9. **Non-`.xlsx` files**
   - Ignore them entirely.

10. **Corrupted workbook**
   - Catch exceptions during load/save and skip the file rather than stopping the entire run, if robustness is desired.

   - PCA cannot run.
   - Should raise an informative error.

2. **Only one numeric column**
   - PCA with 2 components is impossible.
   - Should raise an informative error.

3. **All values missing in a numeric column**
   - Mean is `NaN`, so filling with mean won’t help.
   - Need a fallback strategy, such as filling with `0` or dropping that column.

4. **Rows with all numeric values missing**
   - After mean imputation, those rows can still be handled as long as each column has a valid mean.

   - PCA can technically run, but zero-variance columns contribute nothing.

   - PCA may fail or be meaningless because variance estimation is degenerate.

# article-INoT

Научная статья о ролевых инструкциях и числе вызовов модели при генерации кода. Ревизия **8 сентября 2026 года** теперь основана на **400 настоящих программах, 720 вызовах и официальных тестах BigCodeBench**. Отдельная серия на 200 новых задачах выполняется; её результаты пока не заявляются.

## Модель и прозрачный учёт

**GPT-5.4 mini, medium reasoning, официальный Codex CLI 0.153.4**, канал подписки. Опубликованные стандартные API-тарифы за миллион токенов: **$0,75 вход / $0,075 кешированный вход / $4,50 выход** ([OpenAI](https://developers.openai.com/api/docs/pricing)). Это выбранная недорогая модель для программирования; исследование не устанавливает, что она абсолютно самая дешёвая или оптимальная среди всех GPT.

Для каждого завершённого хода сохраняются фактические счётчики `I` (вход), `C` (кешированная часть входа) и `O` (выход):

`API-equivalent USD = ((I − C) × 0.75 + C × 0.075 + O × 4.50) / 1,000,000`.

Кешированные и reasoning-токены не складываются повторно. Это **условная оценка по API-тарифам, а не счёт подписки**. Отдельно показан расчёт без кеша. Работа исследовательских помощников, подготовка среды и тесты в расходы модельной генерации не включены.

## Выполненный эксперимент

Основной 2×2: **один/три вызова × нейтральные/ролевые этапы**, плюс прямой решатель. Везде одинаковы полный предоставленный контекст и исходное условие; полная история передаётся дальше без сокращений. Компрессия, роутер, малый checker, инструменты и тестовая обратная связь при генерации отсутствуют.

40 задач из заранее зафиксированной случайной development-выборки × 5 условий × 2 повтора = **400 программ**. Это 40 задач, а не 400 независимых наблюдений. Метки повторов не являются управляемыми seed провайдера. Температура и одинаковый жёсткий выходной лимит через CLI не установлены.

Все **400/400 программ и 720/720 ходов** завершены, полностью сохранены и сверены с исходными событиями. Нативный официальный CLI BigCodeBench выполнил все 400 программ; образ, исходники, пакеты, исходные тесты, аргументы и отчёты сохранены. Контроли позволяют оценить качество на 39 задачах: /1005 требует сети для эталона и остаётся общим пропуском. 390 попыток оцениваемы; все 400 учитываются в расходе.

| Условие | Прошло тесты | Средние токены | Средняя условная цена |
|---|---:|---:|---:|
| Прямой решатель | 42/78 | 4500 | $0.00776 |
| Один вызов, нейтральные этапы | 34/78 | 5598 | $0.01251 |
| Один вызов, роли | 39/78 | 5189 | $0.01070 |
| Три вызова, нейтральные этапы | 39/78 | 15636 | $0.02624 |
| Три вызова, роли | 36/78 | 15375 | $0.02543 |

Суммарно: **3 703 821 токен**, **$6,6113451** API-equivalent; без кеша — $7,7687595. Ошибок извлечения итогового формата в этой матрице нет. Все 40 задач и оба повтора показаны в статье. Показаны парные различия и описательные бутстрэп-интервалы по задачам; непотолочный результат не превращён в доказательство неухудшения. Несоответствия отдельных инструкций и тестов опубликованы отдельно и не использованы для удаления неудобных исходов.

## Новая отложенная выборка

Зафиксированы **200 новых задач**, не пересекающихся с development. Выбор идёт по исходной случайной перестановке; восемь примеров, случайно показанных карточкой данных, явно исключены до назначения. После отдельных проверок и поправки зависимостей эталон проходит на **193/200**, отрицательный контроль не проходит на **200/200**. Семь задач сохраняются в назначениях и остаются пропусками для качества.

Серия **1 000 программ / 1 800 ходов** запущена после коммита манифеста. Пока это выполняющаяся серия, а не готовая таблица результатов. [Протокол](reproducibility/revision/HELDOUT200_PROTOCOL.md), [манифест](reproducibility/revision/heldout200_generation_manifest.json), [контроли](reproducibility/results/20260908_codex_mini_heldout200/README.md). Тесты четырёх парных контрастов и поправка Холма заданы заранее. Неухудшение с допуском два пункта не заявляется.

## Настоящий SWE-bench и его ограниченный результат

[Архив отдельной задачи pvlib](reproducibility/results/20260908_codex_mini_swe_dev1/README.md) содержит поиск целых файлов, исходные входы, полные ответы, патчи, реальное применение и тесты неизменённого официального harness. Это замена прежней заглушки `check()`, но пока не большой SWE-bench эксперимент.

Из назначенных десяти патчей два завершились; после превышения лимита 180 секунд серия остановилась без повторов. Прямой патч применился, но не прошёл регрессионный тест; нейтральный был отвергнут применением. Остальные восемь — пропуски. Три хода имеют полные счётчики: 56 796 токенов, $0,1379895 API-equivalent; расход ещё одного недоступен. Эталон работает лишь в явно описанном образе с NumPy 1.26.4; исходный официальный образ и его неуспех сохранены. Контроллер без сети, дочерний контейнер upstream сохраняет стандартную сеть Docker.

## Что остаётся открытым

Самодельные факторные условия не называются INoT, Agentless или SWE-agent. [Отдельная репликация алгоритма INoT](reproducibility/results/20260908_codex_mini_inot200/README.md) уже проверена: **199 полных программ, 96/192 успеха на оцениваемых задачах (50%)**, один пропуск генерации и семь общих пропусков по эталонному контролю. Известный расход — 767 679 токенов, $1,05886035 в эквиваленте API; один вызов не имеет итоговых счётчиков. Это независимо сформулированная адаптация с явными допущениями, не авторский код. Нативные Agentless/SWE-agent, сравнение нескольких моделей и равного выходного бюджета не выполнены. Размещение в Q1 не гарантируется объёмом запусков или редактурой.

[Предшествующий пилот](reproducibility/results/20260908_codex_mini_dev8/README.md) и отвергнутая попытка CLI сохранены отдельно. Исторические 240 записей остаются арифметическим аудитом: полные старые ответы отсутствуют, B3 смешивал выбор контекста с повторными вызовами и расходовал больше простого B0 на трёх меньших длинах. Эти записи не включаются в новые оценки.

## Исходники и сборка

Корневые файлы сохраняют прежние имена и подключают обновлённый текст:

- `converted_article_springer.tex` → `sections/revision_en.tex`
- `converted_article_springer_ru.tex` → `sections/revision_ru.tex`
- `sections/revision_references.tex` — общая проверенная библиография.

Существующая сборка использует MiKTeX и latexmk:

```powershell
.\build.ps1 all
```

Отдельно: `.\build.ps1 ru` или `.\build.ps1 en`. Для принудительной пересборки после устранения ошибки: `.\build.ps1 all -Force`. Обёртки `ab.ps1`, `build-ru.ps1` и `build-en.ps1` сохранены. Ошибки сборки и неразрешённые ссылки теперь останавливают сборку, даже если на диске остался старый PDF.

## Проверка данных и программы

```powershell
python -m pip install -r reproducibility/requirements-publication.txt
python -m pytest reproducibility/tests -q
python reproducibility/audit_legacy.py
```

Актуальные команды проверки полных архивов, подписочной генерации и официальной оценки находятся в [руководстве воспроизводимости](reproducibility/SCALE_GUIDE.md). [Прежний API-протокол](reproducibility/REVISION_GUIDE.md) сохранён как исторический этап. Программные тесты используют искусственные фикстуры и не являются экспериментальными результатами.

Ключ OpenRouter хранится локально, никогда не коммитится. Все новые запуски должны использовать один общий бюджетный журнал; лимит $300 нельзя обнулять созданием новой попытки. Для исходов с неопределённым списанием автоматический повтор запрещён.

## Что установлено

Повторный расчёт 240 исторических записей Flash-Lite подтверждает экономию пакета B3 относительно трёхвызовного B2 на 49.6–90.3%. Но относительно простого одновызовного B0 при контекстах 256, 1024 и 4096 B3 **дороже на 85.0%, 37.5% и 10.3%**. Это центральное уточнение новой версии.

У B3 в 48 из 80 записей есть дополнительный `rerun`: среднее число вызовов — 1,6. Его конечные метки не являются pass@1 одной попытки. Сохранённые метки качества везде равны единице, полные старые ответы отсутствуют. Поэтому арифметику расходов можно проверить, а исходное исполнение решений — нет. Польза ролей, неухудшение качества и официальный результат SWE-bench не доказаны.

## Что изменено

- Полностью переработаны русская и английская рукописи, обновлены оба PDF.
- Новый основной 2×2: **один/три вызова × нейтральные/ролевые инструкции**. Полный предоставленный контекст одинаков, компрессия отключена во всех ячейках.
- RouteMode, малый checker и недоказанные TCO-выводы исключены из основных вкладов.
- Подготовлены сохранение полных API-ответов, общий журнал расходов, экспорт официальных predictions и парный анализ с учётом пропусков.
- Скачан фиксированный BigCodeBench v0.1.4: 40 случайных задач настройки и 1100 отложенных задач; три seed и две модели заложены в манифесты.

**Новых подтверждающих LLM-генераций и официальных оценок в этой версии нет.** Цель 26400 генераций — план, а не результат. Консервативный верхний расход двух полных матриц около $404.42; авторский предел — $300 суммарно. Доступный объём должен быть зафиксирован после настройки и до просмотра подтверждающих результатов. Оригинальный INoT, Agentless и SWE-agent ещё требуют настоящих запусков.

Это не заявление о готовности к Q1/A* или гарантированном принятии. Статья честно отделяет выполненный аудит от ещё не полученного большого эксперимента.

## Исходники и сборка

Корневые файлы сохраняют прежние имена и подключают обновлённый текст:

- `converted_article_springer.tex` → `sections/revision_en.tex`
- `converted_article_springer_ru.tex` → `sections/revision_ru.tex`
- `sections/revision_references.tex` — общая проверенная библиография.

Существующая сборка использует MiKTeX и latexmk:

```powershell
.\build.ps1 all
```

Отдельно: `.\build.ps1 ru` или `.\build.ps1 en`. Для принудительной пересборки после устранения ошибки: `.\build.ps1 all -Force`. Обёртки `ab.ps1`, `build-ru.ps1` и `build-en.ps1` сохранены. Ошибки сборки и неразрешённые ссылки теперь останавливают сборку, даже если на диске остался старый PDF.

## Проверка данных и программы

```powershell
python -m pip install -r reproducibility/requirements-revision.txt
python -m unittest discover -s reproducibility/tests -v
python reproducibility/audit_legacy.py
```

Подробные команды скачивания, манифестов, API-генерации, официальной оценки и анализа находятся в [руководстве](reproducibility/REVISION_GUIDE.md). Программные тесты используют искусственные фикстуры и не являются экспериментальными результатами.

Ключ OpenRouter хранится локально, никогда не коммитится. Все новые запуски должны использовать один общий бюджетный журнал; лимит $300 нельзя обнулять созданием новой попытки. Для исходов с неопределённым списанием автоматический повтор запрещён.

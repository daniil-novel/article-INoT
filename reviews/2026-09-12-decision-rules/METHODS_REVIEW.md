# Bounded statistical reporting audit: large-study appendix

Date: 2026-09-12

## Scope and limits

This is a preparatory, read-only audit of the planned large-study methods. It uses only the requested local sources: the English and Russian standalone details, the frozen factorial analyzer and Luna protocol, and the SCC analyzer and protocol. It does not inspect live study outcomes, execute models, run native tests, or modify frozen analysis or manuscript files. Therefore it cannot assess realized missingness, observed effect sizes, or whether any edge case occurred in the data.

## Verified implementation facts

### Factorial component extension

- The four planned primary contrasts are SR–SN, MR–MN, MN–SN, and MR–SR (`reproducibility/scale1000/analyze.py:21-26`; `reproducibility/scale1000_luna/protocol.md:74-89`). Holm correction is over exactly four p values at familywise alpha .05. Direct-arm contrasts, interaction, subgroups, repeat variability, and resources are descriptive (`analyze.py:205-240`; `protocol.md:92-98`).
- The inference cluster is the task. Replicates 101, 102, and 103 are averaged within task and arm, and a task enters a contrast only when all three outcomes are available in both arms. The 3,000 repeats and 15,000 candidate assignments are not independent observations (`analyze.py:1-5, 94-106`; `protocol.md:26-31, 76-80`).
- The quality test is a two-sided one-sample t test of task-level mean differences, using SciPy `ttest_1samp`; this is explicitly the large-sample approximation (`analyze.py:114-117`; `protocol.md:82-85`).
- Quality bootstrap intervals use 10,000 whole-task resamples after repeat aggregation, generated by `numpy.random.default_rng(20260909)`. The code takes the 2.5th and 97.5th percentiles with NumPy's default linear quantile method (`analyze.py:31-37, 136-140, 236-240`).

### SCC comparison

- The two and only two primary contrasts are SCC–SR and SCC–SN. SR–SN is descriptive. Holm's family size is two and remains two even if one test is unestimable (`reproducibility/revision_20260911/scc_analyze.py:11-17, 146-155`; `scc_protocol.md:101-112`).
- The inference unit is again the task, with the three repeat outcomes averaged within task and method. Replicates 101–103 are repeated executions, not provider random seeds (`scc_analyze.py:82-88`; `scc_protocol.md:21-29, 101-105`).
- SCC quality contrasts use a two-sided one-sample t statistic on the paired task means (`scc_analyze.py:123-125, 158-166`; `scc_protocol.md:101-108`). The protocol specifies an unestimable test as reported unestimable and assigned p = 1 for multiplicity adjustment; the code keeps the output p field null while retaining the two-member family size in Holm adjustment (`scc_analyze.py:146-155, 158-166`; `scc_protocol.md:106-110`).
- SCC quality bootstrap intervals use 10,000 task resamples from `random.Random(20260911)`. Each resample draws task indices with replacement, retains the task's already aggregated value, and uses a sorted order-statistic percentile with linear interpolation at position `(n-1)p` (`scc_analyze.py:128-143`). This is the same interpolation rule as NumPy's default linear method, expressed explicitly.

### Resource estimands

- In the factorial analyzer, resource contrasts are descriptive and use complete three-repeat task pairs. Each arm's three resource values are averaged within task; the reported ratio is the ratio of sums of left and right task means (`ratio_of_task_mean_sums`), which is algebraically the ratio of the corresponding paired sample means when the denominator is nonzero. Difference and ratio intervals use the same factorial bootstrap seed 20260909 (`analyze.py:28, 143-157, 211-212`).
- In SCC, resource contrasts use complete three-repeat task means. The code reports both the mean of task-level ratios (dropping pairs with a zero right-hand denominator) and the ratio of means across complete pairs. Their task-bootstrap seeds are 20260912 for differences and 20260913 for ratios, obtained from the base seed 20260911 plus one and two (`scc_analyze.py:267-296`; `scc_protocol.md:124-133`).
- Resource intervals remain descriptive evidence about recorded resource use. They do not imply quality preservation, cost-and-quality superiority, equivalence, or non-inferiority (`scc_protocol.md:124-133`; `standalone_details_en.tex:51-53`). If resource results are later reported, the table or caption should identify which ratio is shown, because “ratio” can mean the mean of per-task ratios or the ratio of paired means in SCC.

## Constant nonzero paired differences

The frozen factorial quality function explicitly detects a constant task-difference vector. For a constant zero vector it emits `p=1.0` and `t_statistic=0.0`; for a constant nonzero vector it emits the implementation sentinel `p=0.0`, `t_statistic=null`, and `degenerate_difference_vector=true` (`analyze.py:103-140`). This is an encoding convention, not a mathematically valid finite t statistic: the sample variance is zero, so the ordinary t statistic is undefined.

The SCC quality function instead sets the t statistic and p value to null whenever the sample standard deviation is zero and the mean is nonzero; its protocol calls this unestimable and says it retains its place in the two-test Holm family with p = 1 for adjustment (`scc_analyze.py:158-166`; `scc_protocol.md:106-110`). This difference is a cross-analyzer reporting convention, not evidence that a constant vector was observed in either study.

If the edge case occurs in the factorial extension, the paper should report the observed constant direction and magnitude, state that the task differences have zero variance and the ordinary t test is undefined, and identify the frozen output as a degeneracy sentinel (`p=0` with null t statistic). It should not describe that sentinel as an ordinary exact p value or claim a planned t-test rejection solely from it. The SCC wording should call the corresponding contrast unestimable and show no numeric p value, while applying the predeclared family correction rule. Any such statement belongs in methods/results footnote text only when the edge case is actually present; the current appendix must not imply that it occurred.

## Recommended short clarification for the standalone paper

The following text is prospective and can be inserted near the expanded-study decision rules. It keeps operational progress out of the methods table and does not assert that the edge case occurred.

### English

> The repeated-study primary analyses use two-sided one-sample t tests on task-level differences after averaging the three repeats within task. If all complete task differences are identical, the ordinary t statistic is undefined because the variance is zero. The frozen factorial analyzer records this case with a degeneracy flag (p = 0 for a nonzero constant difference and a null t statistic); this is an implementation sentinel, not an ordinary t-test p value. The SCC analysis reports the corresponding contrast as unestimable and retains it in the prespecified Holm family for adjustment. This rule is stated prospectively and does not imply that the edge case occurred.

### Русский

> В повторном опыте основные анализы используют двусторонние одновыборочные t-тесты разностей на уровне задач после усреднения трёх повторов внутри задачи. Если все полные разности задач совпадают, обычная t-статистика не определена, поскольку дисперсия равна нулю. Замороженный факторный анализатор записывает этот случай признаком вырожденности (p = 0 для ненулевой постоянной разности и неопределённой t-статистикой); это служебный маркер реализации, а не обычное p-значение t-теста. Анализ SCC сообщает соответствующее сравнение как неоцениваемое и сохраняет его в заранее заданном семействе Холма для поправки. Это правило сформулировано на перспективу и не означает, что такой случай наблюдался.

## Actionable findings

1. Add the short EN/RU clarification above to the standalone decision-rules prose, preferably after the repeated-study t-test sentence. Do not add it to the status table.
2. If outcomes later contain a constant nonzero factorial difference vector, report the degeneracy flag, null t statistic, and sentinel p value together; describe the inferential test as undefined rather than presenting p = 0 as an ordinary t-test result. For SCC, use “unestimable” and retain the two-test Holm family rule.
3. When reporting resource ratios, name the estimand explicitly: factorial ratio of sums of task means; SCC mean task ratio and/or ratio of paired means, with zero-denominator handling stated if the former is shown.
4. Keep any realized edge-case statement conditional until outcomes are inspected. This audit found a rule in code and protocol, not an occurrence in live data.

\subsection{Пересечения исходных задач расширенной выборки}
Дополнительный аудит задан во время серии Luna, описанной в приложении~\ref{app:expanded-studies}. Он охватывает все 1\,140 исходных задач и фиксированную выборку этой серии из 1\,000 задач. Сгенерированные программы и исходы не используются. После нормализации пробелов все выбранные инструкции различаются. Точное сравнение абстрактных синтаксических деревьев эталонных программ удаляет строки документации, сохраняя имена, литералы и структуру. Сходство инструкций определяется коэффициентом Жаккара для множеств последовательностей из пяти слов после приведения регистра и удаления абзаца со стартовым кодом. Связь по близости кода требует не менее 20 вхождений идентификаторов в каждой программе, сходства Жаккара не ниже 0,80 для множеств и 0,70 для мультимножеств идентификаторов, строковых и числовых литералов. Ключевые слова исключаются; написание остальных токенов сохраняется. Это конкретная адаптация поиска дубликатов по токенам~\cite{allamanis2019duplication}, а не проверка семантической эквивалентности.

Объединение связей по сходству инструкций Жаккара не ниже 0,70, близости кода и точным совпадениям даёт 992 связные группы среди выбранных задач: семь групп содержат 15 задач, крупнейшая --- три. Пороги сходства только инструкций 0,50, 0,70 и 0,90 дают 996, 999 и 1\,000 групп. Это разбиения для проверки чувствительности, а не оценки числа независимых по смыслу задач. В частности, /130 и /131 имеют одинаковое синтаксическое дерево эталона. Между выборками также есть пересечения: инструкция и дерево эталона /1120 совпадают с /1121 из отдельного опыта на 80 задачах, а дерево эталона /826 --- с задачей разработки /814. Разные идентификаторы поэтому не гарантируют отсутствия пересечений исходного материала между исследованиями.

Связные компоненты строятся по всем 1\,140 исходным задачам, затем пересекаются с назначенной выборкой. При объединённом правиле семь групп с несколькими задачами имеют состав: \{/1097,/1099\}, \{/130,/131\}, \{/349,/351,/353\}, \{/369,/622\}, \{/401,/413\}, \{/423,/426\} и \{/673,/675\}. Задачи не удаляются. В дополнительном анализе сначала усредняются три повторные разности внутри задачи, затем целые группы выбираются с возвращением 10\,000 раз с начальным состоянием 20260911. Для каждой выборки сумма разностей делится на число выбранных задач: неодинаковые размеры групп не меняют среднее по задачам на среднее по группам. Полученные 95\%-процентильные интервалы условны относительно выбранного графа и остаются отдельными от зарегистрированных тестов. Неравные размеры групп и невыявленные зависимости ограничивают интерпретацию~\cite{mackinnon2023clusters}. Сравнение исходных задач завершено; интервалы на основе исходов ожидают окончания серии Luna.

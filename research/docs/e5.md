# E5 — полная стоимость владения на реальных измерениях

**Связь со статьёй:** §7.6. Эксперимент заменяет синтетическую таблицу TCO
реальными измерениями стоимости B2 и B3 на задачах с разной длиной контекста.

## Что измеряется

Берутся `N` HumanEval-задач, распределённых по контекстам `{512, 2048, 8192}`.
Каждая задача запускается на:

- `B2_ClassicalMAS`;
- `B3_HybridINoT`.

Собираются:

- стоимость `C_inf` в USD и RUB;
- input/output токены;
- latency;
- `pass@1`.

Затем считается:

- средняя разность стоимости `Δ = C_inf^{B2} − C_inf^{B3}`;
- месячная экстраполяция на 10 000 задач;
- bootstrap CI 95%;
- чувствительность к изменению цен на ±25% и ±50%.

## Условие вывода “TCO в пользу B3”

B3 считается экономически выгодной, если:

- нижняя граница bootstrap CI для месячной экономии больше нуля;
- это остаётся верным при price sensitivity sweep до ±50%.

## Как воспроизвести

```bash
python -m inot e5 --n 60 --seeds "42,123"
python -m inot view e5
```

## Почему дизайн эксперимента корректен

- Используется фактический `usage` block OpenRouter, а не ручная оценка.
- Bootstrap строится по task-level разностям стоимости.
- Price sensitivity sweep защищает вывод от изменения цен моделей.

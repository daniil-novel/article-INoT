Dear Editors of Scientific Reports,

Please consider “Repeated full-context calls lowered executable success in a controlled study of language model code generation” as an Article in computing and engineering. The study distinguishes instruction labels from repeated model calls rather than evaluating a compound agent architecture as a single intervention.

Using 1,000 programming tasks and three fresh requests per condition, the controlled experiment finds lower executable success and greater measured resource valuation for the tested three-call full-context workflows. Neither role-label test rejects after Holm correction; the paper does not equate non-rejection with equivalence. An auxiliary published-controller comparison explicitly retains missing-outcome bounds that prevent a full-population ranking.

The results address a practical and reproducible question about the evaluation of language-model workflows. The manuscript uses the journal's results-before-methods structure, includes the complete experimental methods, and supplies five main display items plus a separate Supplementary Information file. Frozen numerical inputs, primary generated programs, native evaluation records and analysis code accompany the submission. Unreleased material and unverified fresh-environment replay are described in the data statement. Substantive AI assistance is disclosed in Methods.

\section*{Supplementary comparisons and sensitivity analyses}
This file preserves the source manuscript's closest-workflow comparison, execution-phase diagnostics, exploratory direct-solver contrasts, old/new task sensitivity and earlier-model corroboration. These tables do not expand the prespecified testing family. Their estimands and uncertainty are described in the main article.

# R1 - Design and methods review

Coverage: I read the complete canonical English `main.tex` and `body.tex`, all nine table-source files, the workflow diagram, the complete bibliography, and all 16 rendered source pages. I also reviewed the JSS adaptation. This report is one methods-focused critic's assessment; it is not a new experimental replication or external peer review.

The strongest feature is the crossed, unchanged-operation intervention. It separates lexical labels from an explicit execution configuration rather than attributing an entire role-based pipeline to role names. The task-paired analysis also retains the correct experimental unit: three repeats improve each task estimate but do not create 15,000 independent tasks. Frozen control eligibility, separate status categories, assigned denominators, and task/component resampling make the conditional estimands inspectable.

Four limits govern the conclusion:

1. **Bundled topology intervention.** Methods state that the contrast includes "repeated full-context transmission and intermediate-response exposure." Three calls also induce additional generation. A pure call-count mechanism, matched-compute effect, or causal explanation through a particular intermediate message is therefore unidentified. This is a confirmed design boundary, not an erroneous contrast. The adaptation's title, contributions and discussion now preserve it; isolation would require a new intervention, not another significance test.
2. **SCC population ranking is unidentified.** Its observed-pair differences are negative, but assigned bounds of `[-12.98,+6.61]` and `[-13.14,+6.43]` percentage points permit either sign. Evaluating 399 retained developer programs does not provide missing final workflow outcomes. This confirmed missingness limit requires new complete observations or defensible additional assumptions for a population ranking. Editorial repair consists of retaining the conditional claim, which the adaptation does.
3. **Replication and stability remain restricted.** The mini study reuses 200 task IDs; phase subsets overlap; immutable model weights and provider seeds were unavailable. Local Git chronology documents prespecification but is not external timestamped preregistration. The 992-group source audit checks specified similarities, not training contamination or all provider correlation. These are disclosed information/design limits; independent tasks, model families and time blocks require new data.
4. **Executable validity is bounded.** Passing original tests is stronger than self-reported correctness, yet reference/incorrect controls cannot validate every natural-language specification. Tools, repository interaction, compression and selective reruns are disabled; fresh native reconstruction remains unverified, and some conversational/SCC source artifacts are withheld. Claims about deployment productivity or full-Hybrid-INoT benefit would require additional evidence. The adaptation explicitly retains these limits.

The resulting JSS contribution is a controlled configuration study with negative evidence and auditable resource accounting. Reframing improves fit; it cannot supply the untested mechanisms or broader settings.

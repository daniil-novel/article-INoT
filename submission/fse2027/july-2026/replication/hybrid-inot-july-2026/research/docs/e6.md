# E6 — Gemini Pro против Gemini Flash-Lite

Эксперимент отвечает на практический вопрос: насколько дешёвая модель
`google/gemini-3.1-flash-lite` хуже дорогой `google/gemini-3.1-pro-preview`
в двух архитектурах:

- `B2_ClassicalMAS` — традиционная мультиагентная архитектура;
- `B3_HybridINoT` — внутренняя ролевая сегрегация INoT.

## Что измеряется

Для каждой пары `(архитектура, модель, длина контекста)` считаются:

- `pass@1`;
- `U_tok`;
- средняя стоимость в USD/RUB;
- разница `pass@1` Flash-Lite относительно Pro в процентных пунктах;
- отношение стоимости Flash-Lite к стоимости Pro;
- парный критерий Вилкоксона по per-task `U_tok`;
- Holm-Bonferroni по всем сравнениям E6.

## Как воспроизвести

```bash
python -m inot api-check
python -m inot e6 --n 20 --seeds "42,123" --suite controlled
python -m inot view e6
```

Для запуска на HumanEval и controlled-context наборе:

```bash
python -m inot e6 --n 20 --seeds "42,123" --suite both
```

## Артефакты

Результаты сохраняются в `results/e6/`.

- `runs.json` — все сырые запуски;
- `summary.json` — агрегаты по модели, архитектуре и длине контекста;
- `flash_vs_pro.json` — парные сравнения Flash-Lite против Pro;
- `E6_VERDICT.md` — краткий вывод;
- `fig_pass_at_1_flash_vs_pro.png`;
- `fig_cost_usd_flash_vs_pro.png`;
- `fig_utok_flash_vs_pro.png`;
- `fig_quality_degradation_pp.png`.

## Почему дизайн эксперимента корректен

- Внутри каждой архитектуры меняется только модель.
- Задачи, seed-ы и длины контекста совпадают, поэтому сравнение парное.
- Графики подписаны на английском, а документация и выводы — на русском.

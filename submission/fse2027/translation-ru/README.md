# Русская калька статьи FSE 2027

Эта папка содержит полный русский перевод анонимной рукописи из `submission/fse2027/paper`.

- `main.tex` — основной файл перевода.
- `main.pdf` — собранная русская версия.
- `body.tex` и остальные `.tex` — переведенный текст, таблицы и схема.
- `references.bib` — исходная библиография; названия публикаций сохранены в оригинале.

Русская версия предназначена для чтения и обсуждения. Официальной подачей в FSE 2027 остается англоязычный PDF `submission/fse2027/upload/FSE2027-paper.pdf`. Числа, формулы, обозначения условий, ссылки и границы выводов в переводе сохранены. Цитаты точных экспериментальных промптов обозначены как русский перевод, чтобы не создавать впечатление, будто модели получали русскоязычные инструкции.

Для сборки нужна LuaLaTeX:

```powershell
latexmk -lualatex main.tex
```

# Completed primary study evidence

`scale1000-luna-full.zip` contains one LZMA-compressed `evidence.tar` with the
completed primary study's full evidence tree. Extract the ZIP, then the TAR into
a new directory. The enclosed README explains byte verification, raw-response and
native-report reconstruction, registered statistical replay and source-family
sensitivity replay. Publication dependencies are included as a requirements file.

All 177239 listed evidence files and the manifest itself were reread from the
finished archive and checked against the original names, sizes and SHA-256 hashes.
The separate verification JSON retains every check. The archive is 27524963 bytes;
SHA-256 is `4d0461c57863236242192f044bb6b9f68e0bb2d68e29fb49ca0756c38552ecd8`.

This is a research evidence archive. It has not been anonymized or reduced to the
AAMAS supplement limit, and it is not an upload-ready conference supplement.
